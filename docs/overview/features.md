# 功能介绍

本文档记录当前项目已实现的主要功能

## 信息架构

- 一级导航按单一轴分三组：我的画布（直达）、创作工作台（生图工作台 / 视频工作台 / 影视项目 / 剧本创作 / 工作流）、素材与提示词（我的素材 / 公共素材库 / 提示词库）；轴是主舞台 / 创作 / 资产，不再混用渠道与内容形态
- 导航 label、页面标题与浏览器标签标题三处一致；页头 eyebrow 统一中文，只表示所属域（画布库 / 创作工作台 / 素材与提示词）
- 首页提供 Banner 轮播、最近画布、创作入口宫格和提示词库展示区；公共素材库是团队内容入口，不进创作入口宫格，宫格为 8 项
- 角色与场景库 `/film/library` 不进一级导航，从影视项目内进入
- 画布编辑页 `/canvas/[id]` 隐藏站点头部，工具栏与保存状态融入画布界面
- `/account` 承载算力点、充值、订单和开票；`/admin` 是独立管理后台；`/tokendance/callback` 用于第三方模型渠道 OAuth 回调并写入用户渠道配置

## 画布项目

- 支持创建多个画布项目
- 登录后画布项目和“我的素材”支持账号同步，多设备间按时间戳合并
- 画布库支持按标题搜索、分页浏览、缩略图由本地存储重建，卡片可重命名、删除、批量选择和批量删除
- 支持单个画布项目导出为 JSON，也支持从 JSON 导入画布
- 未登录时画布项目保存在浏览器本地；登录且账号同步可用时，会同步保存到账号/云端
- 顶部保存状态同时反映云端同步结果，同步失败可就地重试

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆（5%–500%）和重置视图，视图菜单提供查看全部、聚焦选中、100%
- 支持小地图定位，可开关小地图
- 支持点阵、网格线、空白三种背景
- 支持浅色和深色主题
- 支持鼠标（滚轮缩放）与触控板（滚轮平移）两种操作方式，可开关节点图片信息显示
- 支持框选、多选、全选、取消选择、删除选中
- 支持复制粘贴节点和节点之间的连线
- 支持撤销和重做节点、连线、视口、背景和助手会话变化
- 删除图片、视频和音频节点后，仍被最近 10 条撤销/重做历史引用的媒体文件会保留；历史淘汰、重做记录被新操作丢弃或站内离开画布销毁历史后，通过现有引用检查清理无引用的云文件
- 云文件清理保留仍被其他画布、“我的素材”等使用的文件，并识别仅保存相同 URL 的引用；离页时会接续尚未执行的历史清理，无待清理媒体时跳过全局清理
- 删除节点或清空画布后，撤销可恢复原任务及删除期间返回的结果；任务记录不随节点立即删除
- 支持节点连线，并高亮当前节点相关的上下游节点和连线
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片
- 顶栏画布菜单提供主页、我的画布、新建画布、清空、删除、导入素材、撤销和重做，画布标题可就地编辑
- 生成中的连线显示激光流动效，开启「减少动态效果」时关闭
- 节点随画布缩放做 LOD 收敛：低缩放下隐藏次要文字、把操作图标化，并限制反向放大
- 触屏已支持拖动节点、四角缩放和连线，coarse pointer 下手柄自动加大；触屏框选暂不支持

## 节点

目前画布中有十类节点：

- 图片节点：展示上传图片、生成图片或素材库图片
- 文本节点：保存提示词、说明文案、AI 文字回答等文本内容
- 生成配置节点：汇总上游文本和图片，统一配置模型、比例、数量后批量生成图片或文本
- 视频节点：承载参考视频、生成结果和音频分离
- 音频节点：承载配音生成结果和音频截取
- 全景图节点：支持文生全景、图生全景和本地 2:1 全景图导入，可作为导演台环境背景
- 导演台节点：支持在独立 3D 场景中布置角色、模型和机位，连接画布图片作为全景图，并将机位截图发送为自动连线的画布图片节点
- 组节点：把多个节点框在一起，支持建组、解组和组内生成；批量出图的“图片组”不是组节点，而是图片节点的父子结构
- 素材源节点：解析抖音图文链接，把原图与文案铺开成画布节点
- 发布节点：把上游文案和图片组装成抖音图文并扫码发布

节点支持：

- 拖拽移动，接近其他可见节点的同侧边缘或中心时自动对齐吸附并显示辅助线
- 四角缩放
- 图片节点等比缩放或自由比例切换
- 查看节点基础信息和 JSON
- 删除、复制、粘贴
- 通过左右连接点建立上下游关系
- 提示词面板内读取上游文本与图片，并调整参考图输入顺序

## 图片节点工具

图片节点悬浮工具栏和右键菜单提供以下操作，快捷项可自选并持久化：

- 复制提示词、反推提示词
- 替换图片内容、查看大图
- 锁定比例 / 自由比例切换
- 局部重绘（蒙版编辑）
- 裁剪，裁剪结果生成为新的图片节点
- 切图，按行列把图片切分为多个新节点
- 放大，本地高清插值 / 双线性 / 最近邻，目标 1K / 2K / 4K，不消耗算力点
- 多角度变换，左右、俯仰、镜头距离配合标准 / 广角，结果生成为新的图片节点
- 全景图节点不提供“替换图片”

视频节点支持分离音频并生成音频节点；音频节点支持截取音频片段。

## 批量生成

- 多选图片或在组内一键串行生成，逐个提交、逐个轮询，避免并发打满渠道
- 生成前确认框显示模型与预计算力点，单任务超时与活跃度宽限可中断
- 进度浮层常驻显示「批量生成 N/M」、当前节点标题、成功与失败数量和百分比
- 支持停止全部（中断当前活动节点）和仅重试本批失败项
- 素材源的「生成全部复刻配图」复用这套队列，按复刻序号顺序出图

## 摄像机

- 图片节点、视频节点以及生成配置节点的图片/视频模式，在模型和通用配置旁提供摄像机入口；全景图、文本和音频模式不显示
- 支持开启或关闭摄像机提示词，并可选择相机、镜头、焦距和光圈
- 摄像机生成结果会保留结构化摄像机配置，失败重试时重新组装一次
- 摄像机配置按节点独立保存，复制节点和生成结果可继承配置，刷新或重新打开项目后恢复；入口高亮状态与开启状态同步
- 摄像机面板适配画布浅色和深色主题，跟随所属节点移动，并在画布缩放时保持固定显示大小

## 全景图

- 工具栏“导演台”左侧提供独立的全景图节点，节点类型为 Panorama
- 支持文字生成全景，也支持在全景节点上传图片或连接图片节点，作为 AI 参考图生成全景
- 全景生成固定请求 2048x1024；生成设置仅显示质量和生成张数，不显示尺寸或宽高比
- 生成成功的全景结果会以球形等距柱状环境发送至导演台；普通图片仍按普通背景显示
- 通过“上传素材”或拖入画布导入本地严格 2:1 图片时，可选择“作为全景图导入”或“作为普通图片导入”；前者可直接连接导演台

## 导演台

导演台从画布节点打开；每个导演台节点拥有独立的 3D 场景数据，关闭后可恢复，登录且画布同步可用时会随画布项目同步

- 导演视角 / 机位视角切换
- 内置8种不同的人物，20种不同的人物姿势
- 角色、群演、基础几何体和机位快速添加，群众阵列，想多少人就可以多少人
- 机位拍摄、截图记录和基础镜头管理，支持编辑摄像机位置、注视目标和视野角度；摄像机面板按已选机位在当前时间的位置、旋转和 FOV 生成机位截图，工具栏可独立生成当前导演视角及四/十二方位截图
- 视口比例框、九宫格、平移 / 旋转 / 缩放控制；导演视角与方向球共用平滑阻尼转向
- 支持角色、我的模型和摄像机的场景树管理，可选中对象并设置可见性、锁定状态及位置、旋转、缩放等属性
- 全景图导入与背景调节，支持场景缩放、平移、旋转、地面、天空颜色和全景背景，以及选择、移动、旋转、缩放等视口操作；编辑网格默认显示并可独立关闭，不影响网格吸附
- 底部时间轴可开关并拖动调整高度，自动读取角色、模型、合并后的群众组和全部机位；轨道选择与场景树及右侧属性面板保持同步
- 模型和角色支持位置、旋转、缩放关键帧，角色支持姿势关键帧，机位支持位置、机位旋转和 FOV；群众的各项属性统一保存为组轨道
- 关键帧支持手动添加/删除、自动帧、单帧拖动和对象范围等比例伸缩；拖动时实时合成被拖属性与目标时间的其他属性，松手后一次保存并支持撤销
- 属性轨道可展开速度曲线，支持独立调整进入/离开控制柄、双击单柄复位和相邻动画段曲线预设；预设面板支持点击外部关闭，越界控制柄会在有限范围内自动适配显示
- 时间轴支持 30 FPS 关键帧吸附、最高 60 FPS 连续播放预览、默认循环播放、空格播放/暂停、滚轮横移及 `Ctrl/Cmd + 滚轮` 缩放；角色和活动机位可在导演视角显示位置轨迹
- 当前活动机位可导出固定 1280×720、30 FPS 的 H.264 MP4；导出内容仅包含机位内的 3D 场景，并复用截图输出链路在画布创建视频节点和连线
- 支持本地导入模型并保留模型布置数据；模型文件仅保存在原设备浏览器，缺失时会标记为缺失，重新导入后可恢复原有位置、旋转、缩放等配置
- 图片节点连接到导演台后可作为可选择的全景图；解除连接后会从导演台素材中移除
- 摄像机截图列表仅保存在当前浏览器，可单张或批量清空、查看和发送到画布，不随账号跨设备同步
- 发送截图后会在导演台右侧创建真实图片节点并自动连线；连续单张和批量截图均纵向排列，默认只保存在当前浏览器，不自动上传云端，仍可通过图片节点现有功能手动上传
- 删除导演台节点只移除相关连线，已发送到画布的图片节点会保留

## 素材源节点（抖音图文）

- 工具栏“更多”内提供素材源节点，当前平台只支持抖音图文链接，粘贴分享文案即可解析
- 解析由后端完成：从分享文案提取链接、跟随短链解析作品 ID、抓取分享页内嵌数据并归一化为标题、正文、话题、作者和互动数
- 解析的图片数量、单图体积和全局并发都有上限，可中途取消；取消或失败时保留上一次解析结果，只提示错误
- 解析出的图片优先转存到用户个人云存储，失败时回退保留原 CDN 地址并在标题栏给出警告
- “展开素材”按每张原图铺开一个图片节点，并生成一个汇总标题、正文和话题的文本节点；重复展开做增量替换，已连到外部的派生节点保留
- “一键复刻”在展开素材基础上追加复刻文案节点，并按“一张原图对一张复刻图”创建配图节点，逐图提示词标注第 N/M 张，生成尺寸按原图比例吸附到标准档位
- 复刻流程分三步：文案、配图、创建或打开发布节点；文案未就绪时配图入口禁用
- 后台提供解析开关和每用户限频，解析成功与失败均写入结构化日志便于排查

## 发布节点（抖音图文扫码）

- 发布节点自动汇总上游文本节点作为文案、上游图片节点作为配图（按连线顺序去重），并生成草稿：首行截断为标题、正文与话题自动提取
- 发布面板支持图片勾选与拖拽排序、标题/正文/话题编辑、抖音手机图文预览（3:4 轮播）与预检结果展示，预览仅示意，实际以抖音编辑页为准
- 预检校验标题长度、正文长度、话题数量、图片数量与尺寸比例、图片是否已转存到公网 HTTPS 地址
- 发布图片只支持 JPG/PNG；WebP、GIF 等格式在浏览器内转码为 JPG（透明区域铺白底）后再转存，解析或转码失败会提示改用 JPG/PNG
- 发布图片先本地转存到对象存储或服务器发布目录，再通过 `publicBaseUrl` 提供公网回源，不强制依赖 OSS；发布目录有保留期和定时清理
- 签发走抖音开放平台 H5 Schema：服务端换取凭证并生成带签名的分享链接与二维码，用户在抖音 App 内扫码后进入发布编辑页
- 发布记录状态只有“已签发”和“已确认”；确认由用户在抖音完成发布后回填作品链接，作品链接可在节点卡片点开
- 草稿内容变更后二维码标记为旧内容，需要重新生成；二维码有效期到期自动提示
- 后台提供抖音发布配置（含 Mock 模式）和凭证连通性测试，测试只回有效期不输出凭证
- 发布签发与媒体上传各自有每用户限频；未配置公网地址或使用非 HTTPS 时给出明确错误提示

## 生图工作台

- 生图工作台复用画布紧凑图像设置面板，支持尺寸、质量、生成张数配置，生成记录可保存提示词、参考图、模型和结果媒体并用于回填
- 支持侧边 / 底部布局切换并本地持久化布局选择，可拖拽唤起工作流入口，底部模式与完整设置面板共用尺寸预设，包含常用比例、2K 和 4K 尺寸
- 支持多任务并发提交、串行批量生成、任务停止和刷新恢复；停止会中断前端请求或 SSE，保留已停止结果并可重新生成
- 结果与历史按分类管理，支持新增、改名、删除和移动，删除分类后结果归入未分类；历史结果默认窗口展示，底部「加载更多」分页展开
- 参考图支持剪切板、上传和素材库三种来源，并显示参考图数量与图片体积
- 支持局部重绘、下载、转存云存储、加入“我的素材”和生成前的预计算力点提示；结果网格按视口宽度响应 2–4 列
- 图片生成记录会过滤空缩略图地址，避免渲染无效图片
- 生图工作台和创作工作流会通过后端图片任务保存生成中状态，刷新、切换页面、关闭后重开或多设备登录都能恢复任务，并在完成或失败后更新同一条结果记录
- 生图结果支持账号生成记录同步、按分类查看、历史删除同步软删除和后端任务清理
- 画布图片节点、侧栏、引用栏和生图工作台结果支持本地 WebP 缩略图缓存；后台最多并行处理两张，刷新后复用，画布放大和大图查看仍使用原图
- 生图结果卡片和历史卡片点击重试时，会使用原卡片保存的模型、渠道、尺寸、质量和参考图配置
- 支持上传图片到新节点、拖拽图片文件到画布和生成失败后重试
- 图片节点的裁剪、切图、放大、多角度变换和局部重绘见「图片节点工具」
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果并设置主图；切换主图或删除主图后，文件标识和媒体信息随当前图片同步更新
- 生图工作台、画布多图和创意工作流分别保留每张生成图片的云端地址与文件标识；图片按实际自然宽高保存，重新打开后可继续预览、引用和加入“我的素材”
- 已有普通图片或全景图片节点继续生成时，会同时传递当前节点图片与全部连线参考图；连线图片按提示词编号顺序传递，当前节点图片作为待编辑基础图

## 视频工作台

- 与生图工作台共用侧边 / 底部布局、历史窗口、任务恢复、停止和按原卡片参数重试链路
- 支持本地生成记录、登录后历史同步、失败详情和远程视频下载
- 参数区包含清晰度、按比例换算的实际尺寸、时长滑杆与独立数值输入、生成声音和水印；底部模式按模型能力展示清晰度档位
- 通用视频设置支持 `480p`、`720p`、`1080p`、`2K`、`4K`，切换清晰度时按当前比例同步宽高
- 模型时长滑杆按普通范围、固定档位、AutoDL 动态范围和模型专属规则显示，支持 Seedance 智能时长和 Wan3 智能 / 2–30 秒
- 画布与工作台视频设置支持首尾帧、角色朝向参考、多镜头分镜（自定义 / 智能分镜加分镜提示词列表）、负面提示词和最多 3 个 `@` 引用元素
- Kling 面板独立提供模式、尺寸、时长（v2.6 档位、v3 数值范围）、生成音频、角色朝向参考、多镜头分镜和元素列表，并按模型规则校验参数组合
- Seedance 参考素材有数量与体积上限，方舟 Seedance 统一按一份素材上限处理；2.0 生成时长最高 15 秒，2.5 最高 30 秒
- 普通 Seedance 2.0 的分辨率可以直接输入，包括 `1080p` 和 `4k`；fast、mini 和 2.5 模型保持原面板
- 方舟参考图片支持公网 URL 或 Base64，参考视频和参考音频需要方舟服务器能够访问的 URL
- 视频生成可从文本节点读取 prompt，从图片节点读取参考图，从视频节点读取参考视频，从音频节点读取参考音频
- Seedance 返回远程视频 URL 时，前端会尽量下载为本地 Blob 持久化；如果因 CORS 或网络限制无法下载，会保留远程 URL，后续是否可播放取决于上游 URL 的有效期

## 配音与音频生成

- 音频生成走 `/v1/audio/speech`，可选声音、格式、语速和声音指令
- 默认模型、声音、格式、语速和指令在系统配置中设置，登录后可随账号同步
- 支持 OpenAI 音色列表与 GLM-TTS 音色，可选格式与语速范围按模型收敛，越界自动归一
- MiMo、AutoDL 等音色克隆协议需要一个参考音频节点
- 音频节点支持截取片段；视频节点支持分离音频生成新的音频节点
- 音频任务走后端持久化链路，支持刷新恢复与停止
- 目前没有独立音频工作台页面，配音入口在画布音频节点、影视镜头声音字段和 Agent 工具中

## 影视项目（短剧 / 漫剧）

影视走「项目制 + 分阶段」生产线，与自媒体共用生成引擎、渠道和素材体系，但使用独立页面与数据入口。项目、角色库和场景库目前全部保存在浏览器本地，JSON 导入导出是唯一迁移方式。

项目列表：

- 卡片显示阶段、视觉风格与导演风格、集/场/镜数量、画幅、出图出视频完成度和更新时间，顶部有项目、场次与完成度统计
- 新建入口目前只有空白项目（名称、画幅、视觉风格预设与补充、导演风格、目标时长）；模板库尚未实现
- 单卡支持重命名、导出 JSON 和删除（删除前统计确认），支持导入项目 JSON；列表页暂无搜索与批量操作
- `/film/library` 是跨项目角色库与场景库，可查看详情和删除；导入项目时生成独立副本

阶段 01 剧本：

- 三栏布局：剧本导入、集-场-镜结构树、分镜详情
- 「AI 解析并拆分镜」按文本分块提交，上下文超限自动二分重试，产出镜号、景别、时长、画面、角色、覆盖、镜头语言、光线、色彩、转场、图片与视频提示词、负面提示词、表演和音效设计
- 已有分镜时区分覆盖导入与追加导入，保留最近 3 次解析快照，可一键撤销解析
- 「导入剧本并分析」支持 txt / md / docx / fountain / fdx，先规则切分集、场、对白和出场角色，再逐场做 AI 语义分析（人物关系、节拍、摘要、情绪、制作备注），结果进入待确认列表，可逐条编辑、接受或忽略；关系数据带场次范围与演化维度
- 同一剧本快照可复用，剧本改版后按场次增量只重跑变化场次
- 剧情图谱提供人物关系、场次剧情、剧情节拍和网络四种视图，可导出制作表并把分析出的角色与场景补进项目资产
- 结构代理只产出每场目的、节拍、覆盖与预计时长，可编辑、逐场重生成，旧稿标记为过期但不阻断
- 一致性检查聚合结构覆盖、连续性、风格漂移和资产绑定问题，可跳转到具体镜头
- AI 场记按集生成交接单，场记校验可逐张多模态对照已生成画面，交接单抽屉分页浏览

阶段 02 角色与场景：

- 角色按部位参考包管理（面部、发型、上身、下身、四肢），每项独立提示词、备注、锁定和多图上传，可补齐缺失部位
- 全身三视图合成保留 4 个版本；角色卡在标准与三视图两种版式、白底/灰底、可选道具下由浏览器本地拼合，支持下载 PNG、签名过期提示和存入角色库
- 场景支持主概念图与四视图 / 全景 / 细节特写视图预设，可存入或导入场景库
- 生成分镜时直接引用角色卡与场景卡保持一致性

阶段 03 导演台（分镜）：

- 四种视图：列表（可拖拽入组）、分组板（4 镜或 9 镜一组，整组出图出视频）、表格、画布视图（镜头按场分列，本地平移缩放）
- 支持多选出图出视频（含预计耗时确认）、批量改时长与景别、批量删除、镜头组双向连线与删除自动清理、绑定检查
- 分镜详情分基础、表演·声音、画面、视频四个标签；基础含镜号、景别、运镜、时长、出场角色、场景、镜头语言、跨场移动和「应用风格提示」；表演·声音含目标、情绪、潜台词、肢体、强度与环境音、音效、配乐、对白语气；画面含生成、历史版本切换与删除
- 镜头状态由是否出图、出视频、是否有进行中任务派生，不可手动修改
- 分镜视频支持全参考（角色卡、场景、分镜图自动带入）和首尾帧两种模式，提供分段提示词时间轴（拆分、合并、删除、重置和连续性校验）、最终 prompt 预览复制和历史版本
- 互动分支：变量表支持布尔、数值、文本与初始值；分支规则编辑器提供八种操作符、all/any 条件和 set/add 效果；分支总览、分支图、结局路径和不可达镜头检查

阶段 04 剪辑：

- 目前是顺序预览：片段列表、连播开关、从头播放、总时长与画幅，复用预演抽屉
- 预演抽屉按场分组播放 animatic，支持 1/2/4 倍速和键盘控制，显示总长与目标时长偏差、规则问题列表（时长、覆盖、连续性、风格、分支）和风格检查得分
- 互动模式下预演会按条件弹出分支选项并临时应用效果，不写回项目
- 导出成片、多轨剪辑、字幕与音频轨尚未实现

生成与恢复：

- 影视所有图片/视频生成复用通用任务接口，不复制生成逻辑；任务快照持久化到项目，刷新后按轮询恢复并处理超时与失败
- 影视不创建也不关联无限画布节点，与画布工作台互不引用
- 唯一跨模块耦合是剧本交接，以及影视侧「按最新剧本重新解析」

## 剧本创作

独立于影视项目的写作模块，数据同样保存在浏览器本地。

- 列表卡片显示体裁、logline、梗概、场/角色/字数与约页数、锁定与「已转分镜」状态；支持新建（剧名、类型、题材、logline）、导入、导出 `.txt` 和删除
- 导入支持 txt / md / docx / fountain / fdx 或直接粘贴，先解析预览再导入
- 工作区分五个标签：故事（logline、主题、梗概与下一步规则提示）、人物（want / need / flaw / arc / 小传）、结构（三幕与规则式结构诊断，标出缺目标、冲突、转折、结果或无出场人物的场次）、分场（场景卡含内外景、地点、时间、人物、一句话剧情、四要素、备注与完成度）、剧本（按场正文，可插入对白与转场）
- AI 诊断给出场次成立度评分和 3–6 条问题与改法，只建议不改正文
- AI 润色支持润色文字、加强冲突、补充潜台词和续写；选中片段只改写选区，结果可复制到光标位置
- 版本历史支持命名草稿、场次级 diff（新增 / 删除 / 修改 / 不变、字数增减、人物字段变化）和恢复前自动保留安全稿
- 稿件可锁定；「转 影视分镜」创建影视项目并直接落到分镜阶段，写入来源剧本标识

## 创作工作流

- 工作流是「变量表单 + 提示词模板 + 一次批量生成」的模板，不是节点图；管理后台的渠道工作流图形配置是另一套功能
- 变量支持文本、多行文本、数字、下拉和布尔五种类型；配置含生图参数、系统提示词、提示词模板和负面提示词
- 单图模式与多图系列模式并存，系列模式先由模型拆分提示词再逐张生成
- 系列支持目标张数（1–20）、提示词模型与渠道、拆分说明、逐张审核和 1–6 并发
- 模板区分公开与个人，列表返回公开加自己的；非本人模板只读运行，不可编辑或删除
- 首次启动写入公开种子模板；未登录或同步不可用时保存在浏览器本地
- 「AI 创建工作流」按自然语言需求生成草稿，可预览告警后应用到编辑器
- 运行结果逐张写入生图历史，可在历史页查看、重试和删除
- 运行中任务按父任务聚合轮询，刷新和换设备可恢复；停止只影响仍在生成的图片，已完成结果保留
- 系列草稿的标题与提示词按用户与工作流本地持久化，重新打开运行弹窗后恢复

## AI 生成

- 后端代理会记录 AI 调用日志，包含请求参数、响应、耗时、模型和渠道；管理员可配置本地直连日志上报与日志自动清理
- 图片、视频和音频任务支持后端持久化，刷新、切换页面和关闭后重开都能恢复生成中任务；视频任务由后端全局轮询并同步更新结果
- 画布图片、视频、音频生成及视频工作台支持停止单条任务，停止状态可刷新恢复，停止失败可重试，并行任务互不影响
- 本地直连模式的停止会中断前端请求或 SSE、保留已停止结果并可重新生成；纯本地拼合阶段只能结束后丢弃
- 图片、视频和音频终态任务记录按保留期由后台清理，已取消任务包含在清理范围内
- 生图接口遇到上游连接中断或 5xx 时自动重试一次，并给出更明确的代理/网关超时提示；Midjourney 不做前端自动重试

项目支持两种 AI 调用方式：
- 本地直连：未登录时由浏览器使用本地配置的 Base URL、API Key 和 Model 直接请求 OpenAI 兼容接口；登录后可保存多套本地模型渠道，并通过后端复用项目现有图片、视频和音频转译及任务持久化链路
- 后台渠道：前端请求本项目后端 `/api/v1/*` 代理接口，后端按模型选择管理后台配置的渠道；管理员可控制普通用户是否允许使用后台云端渠道

OpenAI 兼容图像和文本能力继续复用现有接口：

- `/v1/images/generations`：文生图
- `/v1/images/edits`：图生图/参考图编辑
- `/v1/chat/completions`：文本问答和带图问答
- `/v1/audio/speech`：语音合成
- `/v1/models`：读取模型列表；火山方舟协议同样请求所填 Base URL 下的 `/models`，Agent Plan 返回 404 时需要手动填写模型名

视频能力支持两类接口：

- OpenAI 风格视频：`POST /v1/videos`、`GET /v1/videos/{id}`、`GET /v1/videos/{id}/content`
- 火山方舟 Seedance：选择独立的“火山方舟”协议，标准按量 API 使用 `https://ark.cn-beijing.volces.com/api/v3`，Agent Plan 使用 `https://ark.cn-beijing.volces.com/api/plan/v3`；创建任务为 `POST /contents/generations/tasks`，查询任务为 `GET /contents/generations/tasks/{id}`，成功结果读取 `content.video_url`

Base URL 如果已经以 `/v1`、`/api/v3` 或 `/api/plan/v3` 结尾，系统不会再追加 `/v1`。OpenAI 与火山方舟按协议明确区分，不再根据 Seedance 模型名或 Base URL 猜测渠道

除 OpenAI 与火山方舟外，后端渠道协议注册表还内置 Gemini 原生、Grok2api、MiniMax、APIMart、Kie、MiMo、AutoDL、TokenDance 和 Midjourney（异步四宫格文生图，仅支持文生图且不自动重试提交）。每种协议分别约定鉴权方式、模型列表获取、渠道测试和生成链路，未识别的渠道回落到 OpenAI 兼容实现；部分协议使用固定模型清单，渠道测试不会发起付费生成

后台“拉取模型列表”会真实请求渠道 Base URL 下的 `/models`，不会伪造方舟模型结果。如果火山方舟 Agent Plan 返回 404，请手动增加文档列出的可用模型名

后台公开配置可以限制前台可用模型；如果系统可用模型为空，前台会按已启用渠道模型兜底展示

模型分类：

- 前台本地渠道和后台渠道的模型选择弹窗提供「模型分类设置」，可在原面板中为已选模型指定生图、视频、文本或音频类别
- 未手动修改时沿用系统识别，手动分类优先用于模型筛选；不同渠道的同名模型分类互不影响
- 分类随渠道配置保存，刷新、重新拉取模型列表和账号同步后保留；取消模型选择弹窗不保存本次修改

渠道自定传参转译：

- 前台个人渠道与后台渠道的模型选择弹窗提供「自定传参转译」，统一支持图片、视频和音频；配置按真实模型名称填写 `models`，空配置和未配置的模型沿用默认调用，命中配置后出错不回退重发
- 共用编辑器支持代码高亮、变量与配置片段插入和保存校验；配置加载期间仍可选择、分类和拉取模型，取消编辑保留原配置
- 「复制配置说明」包含外层当前渠道 Base URL、完整已选模型列表、全部可用变量、配置规则和结构示例；模型列表以普通文本显示，结构示例以首项演示，不附带右侧编辑器草稿
- 请求可引用现有面板参数与参考素材，支持 JSON、普通 multipart 表单、URL 编码表单和原始内容，以及 JSON、文字和二进制响应；素材变量为 URL/Data URL，表单不会自动把 URL 转成文件，首尾帧与普通参考的互斥通过配置表达式处理
- 相对请求地址追加到渠道 Base URL 的已有路径后，不自动补齐或去重 `/v1` 等前缀；鉴权复用渠道已有密钥，结果与错误支持字段路径或同步提取函数，二进制响应中的错误 JSON 会按错误处理
- 异步接口支持任务 ID、状态、进度和结果提取，可查询多个任务；自定义视频按单次请求使用渠道超时，网络错误、超时或 HTTP 429 时保留任务继续查询，不重复提交生成
- 视频任务保存查询快照，修改或清空渠道规则不改变在途任务；未登录画布同样支持刷新后恢复自定义查询，重试时使用新的快照；同站标准 `/content` 下载保留请求头与查询参数
- 未登录直连在浏览器 Worker 执行配置，个人配置按账号和渠道隔离保存在 localforage；登录后的个人渠道与后台渠道由后端执行，复用费用、退款、任务和媒体存储链路，个人配置可随账号同步；公共配置只返回可匹配的模型名，不返回脚本或密钥

可配置项：

- 本地直连多渠道 Base URL、API Key、模型列表和各类默认模型
- 用户 S3/R2 或 WebDAV 存储配置，登录后可随账号同步
- 默认生图张数、默认音频声音、格式、语速和指令
- 已有内容节点再次生成方式：默认“新建衍生节点”，可切换为“覆盖当前节点”；未登录时本地保存，登录后点击“完成”同步到账号配置
- 图片质量
- 图片比例
- 生成数量
- 视频模型
- 视频比例、清晰度、时长、生成声音和水印

普通图片/文本节点可以直接输入提示词生成结果。生成配置节点可以读取上游节点内容，并按节点自己的配置批量生成多个图片或文本结果。生成配置节点支持预览当前提示词和参考图输入，并调整输入顺序

再次生成设置适用于文本、图片、视频、音频及批量图片子节点；新建保留原结果，覆盖复用当前节点并沿用停止旧任务的流程。全景图、批量父节点和拆层模型沿用原有行为。图片新建时自动使用当前图片作为参考；视频、音频继续使用已连接或选定的参考素材，不自动引用当前媒体。

## Agent

- 画布创作 Agent 使用账号配置的文本模型与渠道调用云端 API，无需本机安装或启动额外 Agent 服务
- 生图
- Agent 设置支持控制图片、视频和音频自动提交；默认关闭时只创建并配置媒体节点与来源连线，开启后直接提交生成任务
- 支持「提交生成前确认」开关；删除节点与连线等高成本、破坏性操作按工具风险注册表触发确认卡
- 执行层提供工具动作审计（调用 ID、风险等级、耗时）、批次原子提交与整批回滚、媒体请求幂等和失败原因反馈
- 助手消息带批次统计脚注，可展开查看本批节点并点击定位到画布
- 媒体确认卡显示预计算力点，本地渠道不计积分时不展示
- 读取当前选中节点作为引用
- 自动把选中节点的上游节点也纳入引用
- 粘贴图片到输入框并插入画布
- 历史会话
- 删除单条或多条会话
- 重试回答
- 把生成的文本插入画布
- 把生成的图片插入画布
- 折叠和展开面板
- 首次成功创建正式主剧本时，可根据创作目标自动总结项目标题
- 手动插入素材、读取或澄清不会消耗首次自动命名机会
- 首次执行非主剧本写操作、导入项目或手动改名后，不再自动覆盖项目标题
- 自动项目标题只修改项目名称，不改写剧本正文、对白、旁白和媒体提示词
- 支持在 Chat 与 Responses 文本接口间切换，默认使用 Chat；模型返回正常文字或澄清问题时会直接显示，只有既无文字也无可执行指令时才提示工具能力错误
- 支持按 ID、关键词或类型查询默认摘要之外的画布节点，并继续读取真实节点详情
- Agent 协议历史达到统一输入估算阈值后，会把较早的完整轮次压缩为长期检查点，同时保留近期完整轮次；空检查点不会替换或删除原历史
- 上下文按优先级裁剪，选中、已确认、参考、上下游和异常节点给明细，其余只提供定位信息；恢复会话时按真实画布校正节点与悬空任务记忆
- Responses 与 Chat 共用现有工具执行链路，工具调用和执行结果按调用 ID 配对；用户未要求整理画布时，`arrange_nodes` 保持不执行并返回明确拒绝结果
- Agent 会使用 `jsonrepair` 修复可安全恢复的 JSON；Provider 明确标记输出未完成、根结构不完整或修复改变结构时禁止执行，并将错误反馈给 Agent 纠正一次
- 单次 JSON 超过 12 个画布操作时整批拒绝；工具调用统一校验名称、必填项、未知字段和参数类型，不将布尔值、数字字符串、非法数组或小数整数静默转换，也不在同批存在无效调用时提前执行其他操作
- 首次协议纠错不占用正常 Agent 步骤；合法省略 `seconds` 时继续使用当前默认时长，关闭自动生成时仍只创建和配置节点

### Agent Skill

- 输入框支持主动选择最多 5 个 Skill；系统 Skill、登录用户 Skill 和未登录本地 Skill 使用同一套选择与执行交互
- 会话会持续使用当前激活的 Skill 组；重新选择后整体替换，执行 Agent 直接读取全部所选根内容，不经过额外模型总结
- 当前用户要求优先于所选 Skill；存在激活 Skill 时按其创作方式、提示词结构和输出格式执行，并加载其根内容与 CORE 公共执行规则，不再叠加内置 WORKFLOW、自动匹配创作模板或 CORE 默认创作路由。没有激活 Skill 时继续使用原有内置流程和能力 Skill 路由
- 按已确认的视频定稿创建节点时，`generate_video.prompt` 会完整保留镜头顺序、时间区间、对白、旁白和资产引用，不摘要删减或额外要求创建文本节点；Skill 不改变阶段推进、画布操作、工具协议和自动生成开关
- 系统 Skill 可包含目录和 Markdown/文本附属文件；只有当前激活且确实包含附属文件的系统 Skill 才提供 `read_skill_file`，并按 Skill 中引用的相对路径读取
- 用户 Skill 保持单文件导入与编辑；未登录时保存在浏览器 `localforage`，登录后按账号隔离保存到数据库
- Skill 根内容和单个附属文件最多 20000 个 Unicode 字符，前端输入限制、字数显示和后端校验采用同一计数规则
- Skill 列表按当前身份缓存并复用进行中的加载请求；后台修改系统 Skill 后使缓存失效，后续重新加载时读取最新版
- 内置视频创作 Skill 只使用当前画布已有的查询、图片、视频、朗读语音、文本和分组工具；缺少搜索、音频分析、剪辑、调色或混音能力时，会询问用户或提供外部处理方案，不声称已经生成无法实际执行的最终合成文件

- 查看提示词详情
- 查看封面和结果图

后台提示词管理支持：

## 素材

“我的素材”未登录时保存在浏览器本地，登录且账号同步可用时可同步到账号/云端，支持：

- 新增文本、图片、视频和音频素材
- 编辑素材标题、封面、分类、标签、来源、备注和内容
- 删除素材
- 按关键词搜索
- 按类型和分类筛选
- 分页浏览
- 复制文本素材
- 下载图片素材
- 从提示词库、画布节点和服务器素材库加入素材
- 在画布中插入素材
- 没有持久化键的本地 `blob:` 图片从画布加入“我的素材”时，会先写入现有 IndexedDB 图片存储；同一浏览器刷新后通过 `storageKey` 重新生成可用地址

“公共素材库”是管理员维护的只读服务器素材库，支持：

- 新增、编辑、删除素材

## 算力点与充值

- 后台云端渠道按模型计价扣算力点，模型单价可按分辨率分别配置，未配置分辨率项作为默认价
- 调用失败自动退款，流水区分 AI 消耗、AI 返还、充值和后台调整
- 余额不足时接口直接拒绝并提示「算力点不足」；前端在生成前展示预计算力点，视频按秒、图片按张数估算
- 本地直连渠道不计算力点，不展示积分提示
- 用户停止任务按“不退还已开始执行任务”的策略处理
- 充值走微信 Native 扫码：创建订单得到二维码，前端轮询订单状态，支付完成后入账；订单过期落为过期态并主动补查网关
- 支付回调同时支持微信 V3（平台证书验签与内容解密）与 V2（HMAC 验签）
- 后台可维护充值套餐，前台按套餐发起充值
- 开票仅允许对本人已支付订单提交申请，后台可查看开票请求
- 支付凭证、appid 与订单有效期等在后台支付分区配置，配置缺失时前台给出明确提示

## 渠道工作流供应商

工作流类渠道支持 RunningHub、ComfyUI 和 AutoDL，与「创作工作流」页面是两套功能：

- RunningHub 支持工作流与网页应用两类条目，后台可远程获取节点图与字段，前台按字段映射表填写输入
- ComfyUI 通过本机桥接程序出网：用户在本地常驻桥接程序，服务端只排队，桥接程序心跳领取任务、执行后回传结果；任务租约有有效期，完成结果短期保留；ComfyUI 仅支持工作流类型并校验桥接程序归属
- AutoDL 作为渠道协议提供自定义鉴权头与工作流目录，前端按 workflow uuid 展示名称，动态时长范围由渠道返回
- 后台提供渠道抽屉、字段映射与测试工作台，可在工作流正式运行前验证入参与产物

## 账号和后台

- 管理后台菜单包含用户、算力点流水、AI 调用日志、提示词、素材库、系统 Skill、充值套餐和系统设置；后台首页直接跳转用户管理
- 管理后台支持系统提示词、AI 调用日志、数据存储和渠道管理配置
- 管理后台支持系统 Skill 的新增、编辑、启用、排序和删除，并支持封面、根内容以及附属目录和 Markdown/文本文件管理
- 系统 Skill 目录支持创建、改名、删除、展开收起和拖拽排序或移动；根 `SKILL.md` 固定作为 Skill 主内容
- 管理后台渠道可用模型支持按“新获取、已有”分组选择，编辑渠道时 API Key 留空表示沿用已保存密钥
- 系统设置分公开与私有两组分区，均支持可视化表单与 JSON 两种编辑模式；私有含提示词同步与日志、内容解析、抖音发布、微信支付、存储和渠道，公开含可用模型与工作流、系统提示词、权限开关和模型算力点
- 渠道抽屉提供单模型测试与批量测试，测试有响应体积上限且不输出凭证
- 管理员配置 S3/R2 或 WebDAV 后，用户上传参考图、生成结果和媒体文件可由服务端上传到对象存储，并在删除时同步清理对象和本地缓存
- 存储支持多个 provider、按权重轮询选择和容量探测，超出容量上限自动停用；管理员可控制普通用户是否使用全局存储、是否允许自带存储
- 管理后台提供默认关闭的“全部素材云端同步”开关，保存配置后对后续上传生效；关闭时保持图片及“我的素材”原有上传方式
- 开启“全部素材云端同步”且用户有可用云存储时，画布导入的音视频及图片生成、编辑、视频和音频生成结果自动转存，沿用全局存储权限并优先使用个人存储；未登录时也可使用已配置且获准使用的个人存储
- 生成结果的自动转存由浏览器收到结果时触发，直接填写素材 URL 或读取已完成历史不会批量转存；同一生成结果重复查询不重复上传，撤销后再次生成及不同任务的结果分别转存
- 云端转存失败会提示“云端同步失败”，保留上游地址或已有文件；Base64/blob 图片可回退到浏览器本地保存，转存失败不改变生成结果的成功状态
- 登录后可将本地 IndexedDB 中的画布、素材、生成记录和媒体文件迁移到云端存储
- 管理员可控制是否允许普通用户注册、是否允许用户自定义渠道，以及普通用户是否允许使用后台云端渠道；关闭后前端隐藏入口，后端同样拒绝
- 登录用户可以同步本地直连模型渠道、画布偏好和用户存储配置
- 支持 JWT 会话，token 与用户信息一并保存在浏览器本地
- `/api/auth/me` 可读取当前用户，未登录时返回访客用户；网络失败或超时保留已有登录态并记录失败原因，只有 401/403 才清登录，受保护页不会因冷启动断网被踢回登录
- 首次启动时可根据环境变量创建默认管理员
- 用户管理支持查询、新增、编辑角色与状态、重置密码、调整算力点和删除用户

## 后端能力

- Gin 提供 API 服务
- Docker 运行时由 Next.js 提供页面入口，`/api/*` 请求代理到内部 Go 服务
- GORM 管理数据库连接和自动迁移
- 支持 SQLite、MySQL、PostgreSQL
- 数据库保存用户与算力点流水、提示词与分组、服务器素材、创作工作流、系统配置与用户配置、AI 调用日志、图片/视频/音频生成日志、画布任务与项目、存储对象、Agent Skill 与附属文件、充值套餐与订单、开票请求、发布记录、Comfy 桥接与请求
- 数据库保存系统与登录用户 Skill；系统 Skill 附属文件单独保存，根内容保持单一来源
- 全新数据库首次启动时会在一个事务中导入项目内置 Skill、附属文件和初始化标记；任一写入失败时整体回滚，已有系统 Skill 不会被重复或覆盖导入
- 业务接口统一返回 `{ code, data, msg }`
- 对象存储支持 S3 兼容（含 Cloudflare R2）和 WebDAV，浏览器可直传后登记；文件读取走 `/api/files/:id/content` 或公网地址
- 未登录画布有独立匿名存储通道，凭会话 Cookie 上传，文件大小受限
- 所有出站取回地址做 SSRF 校验，管理员可按 provider 显式放行内网地址
- 后台调度包含提示词远程源定时同步、软删画布项目清理、发布媒体清理、存储容量探测、AI 日志保留期清理、视频任务全局轮询和 Comfy 桥接唤醒；调度在服务启动时注册，保存设置后按新配置刷新
- AI 调用日志同时记录服务端代理请求与前端本地直连上报，大字段与 Base64 内容做脱敏
- 提供 `/api/health` 健康检查；Docker 镜像分阶段构建前端、后端和本机桥接程序

## 当前限制

- 未登录时画布项目和“我的素材”保存在浏览器本地；登录且账号同步可用时，会同步保存到账号/云端
- 未登录的本地直连模式下，AI API Key 保存在浏览器本地，并由浏览器直接请求配置的 OpenAI 兼容接口；登录用户开启账号同步后，本地渠道配置会保存到账号配置中，用于多设备恢复和后端转译
- 影视项目、角色库与场景库、剧本目前只保存在浏览器本地，尚未接入账号同步；JSON 导入导出是唯一迁移方式
- 影视「剪辑」只做顺序预览，导出成片、字幕与音频轨待接后端合成；角色的表情、比例和动作设定视图尚未接入 UI
- 影视生成不创建也不关联画布节点，与无限画布没有节点级联动
- 素材源解析只支持抖音图文，依赖分享页结构而非官方开放接口，可能随页面变更失效；视频与音频不下载转存
- 抖音发布结果由用户在 App 内完成并手动回填作品链接，服务端不接收发布回调，发布记录没有过期清理
- 发布媒体与解析的限频、抖音凭证缓存均为单进程内存，多实例部署时各自独立
- 视频工作台暂无分类管理，与生图工作台的历史分类不一致
- 后台公开配置「系统提示词」的 image / video / text / workflow 四项前端未消费，生成链路读的是本地配置里的提示词；只有工作流创建 Agent 的提示词在后端生效
- 服务器素材库目前主要保存 URL 或文本，暂未提供文件上传接口
- 火山方舟参考图片支持公网 URL 或 Base64；参考视频和参考音频必须使用方舟服务器能够访问的 URL，浏览器 `blob:`、localhost 和内网地址不能直接使用
- Seedance 返回远程视频 URL 时，前端会尽量下载为本地 Blob 持久化；如果因 CORS 或网络限制无法下载，会保留远程 URL，后续是否可播放取决于上游 URL 的有效期
- 画布更适合桌面端使用，移动端触控体验还未系统完善，触屏框选尚未支持
- 后台支付配置当前存在硬编码默认值，生产部署需覆盖；Docker 静态资源路径目前仍是待办项
