# 画布节点操作手册

本文档记录画布节点的主要用途和操作流程，方便使用和后续开发维护。当前先介绍文本节点。

## 文本节点

文本节点用于保存提示词、草稿、说明文案和 AI 生成的文字结果。它既可以作为独立文本内容，也可以作为下游生成配置节点的输入。

### 编辑文本内容

- 双击文本节点内容区域，直接编辑节点里的文字。
- 选中文本节点后，点击顶部工具栏的“编辑文字”，进入文字编辑状态。
- 顶部工具栏的“缩小”和“放大”用于调整文本节点字号。

### 用下方对话框生成或修改文本

- 选中文本节点后，点击顶部工具栏的“编辑”，打开节点下方对话框。
- 文本节点下方对话框只用于生成或改写文本，不承担生图功能。
- 当文本节点为空时，输入框用于填写想生成的文本内容；点击发送后，结果会回填到当前文本节点。
- 当文本节点已有内容时，输入框用于填写想把本段文本修改成什么；点击发送后，会在右侧生成新的文本节点，并自动连接原节点和新节点。
- 输入内容可以手写，也可以从提示词库选择。
- 对话框里的模型下拉来自全局配置里已拉取的模型列表；选择结果只作用于当前节点，不会修改其它节点或全局默认模型。
- 如果下拉中没有模型，需要先打开配置弹窗拉取模型列表，并设置默认生图模型和默认文本模型。火山方舟 Agent Plan 若提示不支持 `/models`，请手动填写模型名。

### 用文本节点生成图片

- 先在文本节点中准备好要用于生图的文本内容。
- 点击文本节点顶部工具栏的“生图”按钮。
- 系统会在文本节点右侧自动创建一个生成配置节点，并连接文本节点到生成配置节点。
- 生成配置节点会读取上游文本内容作为生图提示词，并立即开始生成图片。
- 后续需要调整模型、比例、数量时，可以在生成配置节点里修改后再次生成。

### 用图片节点继续生成图片

- 选中空图片节点后点击“生成”，会直接在当前节点里生成结果，不再额外保留一个空框。
- 当数量为 `1` 时，生成结果会直接回填到当前图片节点。
- 当数量大于 `1` 时，当前图片节点会作为主图节点，右侧继续生成对应数量的子图节点。
- 如果图片节点本身已经有内容，则会沿用已有图片作为参考图，再生成新的图片批次。
- 每个生成出来的图片节点都会在自身 `metadata` 下记录提示词、生成类型、模型、尺寸、质量、数量和参考图引用，方便后续重试。
- 如果重试时参考图已经丢失或无法恢复，系统会直接提示，避免误发空的图生图请求。

### 视频节点

- 工具栏可以新建视频节点，也可以拖入或上传本地视频文件。
- 视频节点使用原生播放器展示内容，可在节点内直接播放、暂停和拖动进度。
- 空视频节点下方对话框可输入提示词生成视频，结果会回填到当前节点。
- 从文本、图片或配置节点创建视频生成时，会在右侧生成新的视频节点并自动连接。
- 生成配置节点的视频模式会读取上游文本作为 prompt，读取上游图片作为参考图，读取上游视频作为参考视频，并在输入预览里显示参考视频。
- 视频生成接口支持 OpenAI 风格的 `POST /v1/videos`、`GET /v1/videos/{id}` 和 `GET /v1/videos/{id}/content`。
- 使用火山方舟 Seedance 时必须选择独立的“火山方舟”协议；标准按量 API 的 Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`，Agent Plan 为 `https://ark.cn-beijing.volces.com/api/plan/v3`。系统会使用 `POST /contents/generations/tasks` 创建异步任务，并轮询 `GET /contents/generations/tasks/{id}`。
- Agent Plan 专属 `/api/plan/v3` 当前未提供 OpenAI `/models` 模型列表接口，后台不会伪造模型列表；请手动填写 `doubao-seedance-2.0` 或文档列出的其他可用模型。
- 火山方舟 Seedance 的参考图片支持公网 URL 或 Base64；参考视频和参考音频必须是火山服务器能够访问的 URL。

### 推荐流程

1. 新建文本节点，写入图片创作想法。
2. 打开文本节点下方对话框，让 AI 优化或扩写这段提示词。
3. 改写结果会生成到新的文本节点，保留原始文本方便对比。
4. 确认文本节点内容后，点击顶部工具栏“生图”。
5. 在自动创建的生成配置节点中继续调整图片参数或重新生成。

## 素材源节点（抖音图文）

素材源节点用于把抖音图文/视频作品解析成可继续创作的画布素材：文案、话题、作者、互动数据和原图。它只接受出边，不接受上游连入。

### 解析作品

- 通过画布底部工具栏“更多 → 素材源”创建节点；也可以在画布空白处双击，在“添加节点”菜单里选择“素材源”。
- 双击节点打开面板，粘贴抖音作品链接或整段分享文案，点击“解析”。
- 解析成功后，节点和面板会显示标题、正文、话题、作者、互动数据与图片缩略图。
- 解析需要登录；图片需要服务端已配置对象存储（登录用户配置了个人 S3/WebDAV 且后台允许时会优先用个人存储）。未配置存储时会保留原图链接并提示“可能过期”，仍可使用文字素材。
- 解析过程中可以点“取消”中止；重新解析失败时会保留上一次结果，只显示错误提示。
- 解析失败时可在面板里手动粘贴文案，点击“使用这段文字”继续。
- 管理员可在后台“私有配置 → 内容解析”关闭解析功能；关闭后解析入口禁用，已解析素材和复刻节点不受影响。

### 展开素材

- 点击“展开素材”，会在当前节点右侧生成 1 个文本节点（原文 + 话题）和若干图片节点（原图）。
- 生成的素材节点就是普通文本/图片节点，可以继续被文本节点、图片节点、生成配置节点引用。
- 重复点击不会重复生成同名素材节点；重新解析后再展开，会刷新已生成素材节点的内容，复刻文案/配图节点保持你的修改。
- 面板里的“重置素材”会删除由当前素材源展开的素材/复刻节点；已经连到画布其他节点的派生节点会保留，并提示保留数量。

### 一键复刻

- 点击“一键复刻”，会生成 1 个“复刻文案”文本节点，并按素材图片数量生成**同样数量**的“复刻配图”图片节点（原图有几张就生成几张，标题带 1/2/3 序号）。
- 每张复刻配图只连接自己对应的那张素材图，另共享复刻文案；不会把所有素材图都塞进同一个图片节点当参考，避免多图参考互相干扰、顺序对不上。素材没有图片时只生成 1 个纯文生图的复刻配图节点。
- 默认只把原文素材连到复刻文案；多数文本模型不支持读图，需要参考画面时可手动把素材图连到复刻文案（文本模型需支持读图）。
- 节点里已预置复刻提示词，可在节点下方对话框里修改后直接生成；生成结果仍走现有文本/图片生成和任务链路。
- 复刻结果可继续用现有功能修改、重新生成、下载或加入“我的素材”。

### 复刻流程向导

- 复刻节点创建后，素材源面板会显示紧凑的 1/2/3 步骤：
  1. **文案**：显示未生成/生成中/已生成/失败，点「生成复刻文案」或「重新生成文案」。
  2. **配图**：点「生成全部复刻配图（N 张）」；文案未生成时按钮禁用，避免把复刻提示词当成上游文案。
  3. **发布**：配图生成成功后自动创建/复用发布节点并连接文案与成功配图；也可以点「创建发布节点」手动补建，或「打开发布节点」。
- 批量部分失败时，Step2 会出现「重试失败配图（N 张）」，只重试当前素材源的失败项，重试成功后自动补齐发布节点连接。
- 自动创建发布节点仅按 `publishSourceId` 复用本流程创建的节点；手动创建的旧发布节点不会被自动接管。

### 注意

- 解析他人作品时请遵守平台规则；复刻内容应保持原创，发布前自行检查字数、话题、图片规格与联系方式等平台要求。

## 批量生成图片

画布支持把多张图片节点排成队列，一次点击逐张生成，避免十几张图逐个点。

- 框选或多选图片节点后，底部工具栏出现「批量生成」；单张图片被选中时也可以用它重跑。
- 选中组节点后，在「对齐 / 分组」菜单里点「生成组内图片」，会自动收集组内图片节点（`metadata.groupId`）。
- 素材源一键复刻后，面板会出现「生成全部复刻配图（N 张）」，只圈定本次复刻生成的配图，不会带素材原图；文案未生成时会禁用并提示先完成 Step1。
- 开始前会二次确认，显示数量、图片模型和预计算力点；生成时显示当前第 N/M 张、成功/失败数和「停止全部」。
- 批量生成按顺序逐张执行，单张失败不会阻塞后续；停止只停当前和排队任务，已完成的结果保留。
- 每个图片节点只生成 1 张，避免当前全局数量设置让一个节点出多图，也保持素材图与复刻配图一一对应。

## 发布节点（抖音图文扫码）

发布节点用于把画布里的文案和图片组合成一次抖音图文发布；它不参与生成，只负责收集、预检和签发扫码内容。

### 创建与连接

- 通过画布底部工具栏“更多 → 发布”创建，或在画布空白处双击“添加节点 → 发布”。
- 发布节点只接受上游连入，不能从发布节点连线到其他节点。
- 把 1 个文案节点和想发布的图片节点连到发布节点即可；连了哪些图片，发布时就只能选哪些图片。

### 生成发布二维码

- 双击发布节点打开面板，可编辑标题、正文、话题，勾选/排序上游图片。
- 点“生成二维码”后，前端会把选中的图片转存到当前发布域名的 /api/publish/media/，再调用预检和签发。
- 预检不通过时会直接显示中文原因；常见限制：标题不超过 20 字、正文不超过 1000 字、话题不超过 5 个、图片 1–35 张、单张不超过 20MB、仅支持 JPG/PNG、短边不小于 360px、比例在 1:2.2～2.2:1 之间。
- 二维码有效期 2 小时；用抖音 App 扫码后进入抖音编辑页，图片、话题（以及可携带的标题）会带过去，用户确认发布。
- 图片多时二维码会比较密，点“放大二维码”用全屏大图扫码；过期后二维码会置灰，需要重新生成。
- 图文只能进入抖音编辑页，不能做到服务端静默直发；发布完成后可在面板里回填作品链接并标记“已发布”。

### 配置与联调

- 后台“私有配置 → 抖音发布”配置 publicBaseUrl、抖音 Client Key / Client Secret，并可点“测试抖音配置”验证 client_token / open/getticket 权限。
- publicBaseUrl 必须与用户访问画布的域名一致，例如 https://jl.lx.cq.cn；发布图片保存在服务器本地发布目录，通过该域名的 /api/publish/media/ 提供公网 HTTPS 访问，不依赖 OSS。
- MOCK 模式用于权限未联调或本地验证：二维码格式与签名规则相同，但抖音不会接受，不能当成真实发布。
- 发布依赖抖音开放平台 H5 分享能力（h5.share、open.get.ticket，以控制台实际申请项为准）；图片必须能被抖音服务器公网回源抓取。
