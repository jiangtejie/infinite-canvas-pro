# 画布节点操作手册

本文档记录画布节点的主要用途和操作流程，方便使用和后续开发维护。

## 文本节点

文本节点用于保存提示词、草稿、说明文案和 AI 生成的文字结果。它既可以作为独立文本内容，也可以作为下游生成配置节点的输入。

### 编辑文本内容

- 双击文本节点内容区域，直接编辑节点里的文字。
- 选中文本节点后，点击顶部工具栏的“编辑文字”，进入文字编辑状态。
- 顶部工具栏的“缩小”和“放大”用于调整文本节点字号。

### 用下方对话框生成或修改文本

- 选中文本节点后，点击顶部工具栏的“编辑”，打开节点下方对话框。
- 文本节点下方对话框只用于生成或改写文本，不承担生图功能。
- 当文本节点为空时，输入框用于填写想生成的文本内容；点击发送后，结果会回填到当前文本节点。
- 当文本节点已有内容时，输入框用于填写想把本段文本修改成什么；点击发送后，会在右侧生成新的文本节点，并自动连接原节点和新节点。
- 输入内容可以手写，也可以从提示词库选择。
- 对话框里的模型下拉来自全局配置里已拉取的模型列表；选择结果只作用于当前节点，不会修改其它节点或全局默认模型。
- 如果下拉中没有模型，需要先打开配置弹窗拉取模型列表，并设置默认生图模型和默认文本模型。火山方舟 Agent Plan 若提示不支持 `/models`，请手动填写模型名。

### 用文本节点生成图片

- 先在文本节点中准备好要用于生图的文本内容。
- 点击文本节点顶部工具栏的“生图”按钮。
- 系统会在文本节点右侧自动创建一个生成配置节点，并连接文本节点到生成配置节点。
- 生成配置节点会读取上游文本内容作为生图提示词，并立即开始生成图片。
- 后续需要调整模型、比例、数量时，可以在生成配置节点里修改后再次生成。

### 用图片节点继续生成图片

- 选中空图片节点后点击“生成”，会直接在当前节点里生成结果，不再额外保留一个空框。
- 当数量为 `1` 时，生成结果会直接回填到当前图片节点。
- 当数量大于 `1` 时，当前图片节点会作为主图节点，右侧继续生成对应数量的子图节点。
- 如果图片节点本身已经有内容，则会沿用已有图片作为参考图，再生成新的图片批次。
- 每个生成出来的图片节点都会在自身 `metadata` 下记录提示词、生成类型、模型、尺寸、质量、数量和参考图引用，方便后续重试。
- 如果重试时参考图已经丢失或无法恢复，系统会直接提示，避免误发空的图生图请求。

### 视频节点

- 工具栏可以新建视频节点，也可以拖入或上传本地视频文件。
- 视频节点使用原生播放器展示内容，可在节点内直接播放、暂停和拖动进度。
- 空视频节点下方对话框可输入提示词生成视频，结果会回填到当前节点。
- 从文本、图片或配置节点创建视频生成时，会在右侧生成新的视频节点并自动连接。
- 生成配置节点的视频模式会读取上游文本作为 prompt，读取上游图片作为参考图，读取上游视频作为参考视频，并在输入预览里显示参考视频。
- 视频生成接口支持 OpenAI 风格的 `POST /v1/videos`、`GET /v1/videos/{id}` 和 `GET /v1/videos/{id}/content`。
- 使用火山方舟 Seedance 时必须选择独立的“火山方舟”协议；标准按量 API 的 Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`，Agent Plan 为 `https://ark.cn-beijing.volces.com/api/plan/v3`。系统会使用 `POST /contents/generations/tasks` 创建异步任务，并轮询 `GET /contents/generations/tasks/{id}`。
- Agent Plan 专属 `/api/plan/v3` 当前未提供 OpenAI `/models` 模型列表接口，后台不会伪造模型列表；请手动填写 `doubao-seedance-2.0` 或文档列出的其他可用模型。
- 火山方舟 Seedance 的参考图片支持公网 URL 或 Base64；参考视频和参考音频必须是火山服务器能够访问的 URL。

### 推荐流程

1. 新建文本节点，写入图片创作想法。
2. 打开文本节点下方对话框，让 AI 优化或扩写这段提示词。
3. 改写结果会生成到新的文本节点，保留原始文本方便对比。
4. 确认文本节点内容后，点击顶部工具栏“生图”。
5. 在自动创建的生成配置节点中继续调整图片参数或重新生成。

## 素材源节点（抖音图文）

素材源节点用于把抖音图文/视频作品解析成可继续创作的画布素材：文案、话题、作者、互动数据和原图。它只接受出边，不接受上游连入。

### 解析作品

- 通过画布底部工具栏“更多 → 素材源”创建节点；也可以在画布空白处双击，在“添加节点”菜单里选择“素材源”。
- 双击节点打开面板，粘贴抖音作品链接或整段分享文案，点击“解析”。
- 解析成功后，节点和面板会显示标题、正文、话题、作者、互动数据与图片缩略图。
- 解析需要登录；图片需要服务端已配置对象存储（登录用户配置了个人 S3/WebDAV 且后台允许时会优先用个人存储）。未配置存储时会保留原图链接并提示“可能过期”，仍可使用文字素材。
- 解析过程中可以点“取消”中止；重新解析失败时会保留上一次结果，只显示错误提示。
- 解析失败时可在面板里手动粘贴文案，点击“使用这段文字”继续。
- 管理员可在后台“私有配置 → 内容解析”关闭解析功能；关闭后解析入口禁用，已解析素材和复刻节点不受影响。

### 展开素材

- 展开入口在节点悬浮工具栏的「素材」菜单，不在面板里。「展开素材」会在当前节点右侧生成 1 个只读参考文本节点（原文 + 话题）和若干图片节点（原图）。
- 素材文案节点标题为「原始文案 · 参考」，内容只读，手改不会进入复刻；素材图仍是复刻配图的真实数据输入。
- 「更新展开素材」只有来源变化或派生节点内容不一致时可用；同步会保留你调整过的节点位置、尺寸和其他元数据。派生节点被编辑或连到画布组外内容时会阻止更新并指出是哪个节点，不做部分成功或静默覆盖。
- 「重置展开素材」在同一菜单内，用全局确认弹窗二次确认，会删除由当前素材源派生的素材/复刻节点；已经连到画布其他节点的派生节点会保留，并提示保留数量。
- 生成的素材节点就是普通文本/图片节点，可以继续被文本节点、图片节点、生成配置节点引用。

### 交给 Agent 复刻

- 「复刻」在节点悬浮工具栏，点击后先自动展开并同步素材，再挂载创作助手、打开面板并预置复刻指令。也可以直接在对话里说「复刻这个素材源」，Agent 会自己调用 `expand_source` 打通全流程。
- 复刻按独立 RemixRun 进行，每次有独立 runId，旧版本保留。三个工具串成主链：
  1. **设置**：`plan_source_remix` 打开「本次复刻设置」，显式选择内容/营销模式、资料空间、门店、本店可用商品、植入方式与最多 5 个 Skill。设置会记住上次选择，资料或商品已变化时只恢复仍然有效的选项。
  2. **策划**：一次多模态调用同时产出原创文案与整组配图策划，按「一张原图对一张复刻图」创建配图节点，标题带序号，生成尺寸按原图比例吸附到标准档位。每张配图只参考自己对应的那张原图，不会把整组原图塞进同一个节点。
  3. **审阅**：策划节点显示为运行卡片（状态胶囊、运行时间、文案标题、模式与门店、话题、配图完成数与每张状态点），内置「审阅 / 生成配图 / 另做一版」；完整策划双击打开面板查看。悬浮工具栏对策划节点同样只给这三个运行操作。
  4. **配图与发布**：`generate_remix_images` 整组出图，复用批量队列自带的张数/模型/算力点确认；至少一张成功才创建或复用发布节点，发布节点按 runId 复用。
- **组级策划是必经步骤，由代码门禁保证**：策划未完成、配图节点被删或提示词为空时拒绝生成，不能改用单张生图逐张绕过。提交配图前还会复核原素材签名、营销资料快照（门店/商品/已确认事实/图片）、Skill 内容 hash、复刻核心规则版本、文案与策划是否被手改、配图槽位与参考图连线。单张生成、批量生成、失败重试和 Agent 工具共用同一审阅链路。
- 重新解析或修改来源后，工具栏「复刻」旁显示过期警告，旧策划会被门禁拒绝，必须重新策划。重新策划会复用原节点并保留已生成的配图内容，只清空策划正文与配图提示词等新策划写回。
- 重跑配图强制原地覆盖，不会在组外另建兄弟节点导致发布仍用旧图。某张配图被手动展开成多结果批量组时，整组重跑会显式拒绝并指明是哪几张，而不是少生成一张后报成功；该槽位仍属于复刻组，发布节点取它的主图。
- 复制或导入画布时复刻运行标记为 detached，必须重新选择资料并创建新策划；账号切换后旧策划拒绝继续生成。
- 关闭「自动生成媒体」时，`generate_remix_images` 只写齐提示词不提交，由你手动批量生成。
- 复刻结果可继续用现有功能修改、重新生成、下载或加入“我的素材”。

### 注意

- 解析他人作品时请遵守平台规则；复刻内容应保持原创，发布前自行检查字数、话题、图片规格与联系方式等平台要求。

## 生成连线动效

- 节点生成/解析/发布进行中时，连到它的连线上会出现沿路径流动的激光虚线，用来提示数据正在传输。
- 目标节点处于 loading/stopping、素材源解析中，或发布节点正在生成二维码时触发；完成后自动恢复普通连线。
- 系统开启「减少动态效果」时，激光动画会关闭，只保留静态连线。

## 批量生成图片

画布支持把多张图片节点排成队列，一次点击逐张生成，避免十几张图逐个点。

- 框选或多选图片节点后，底部工具栏出现「批量生成」；单张图片被选中时也可以用它重跑。
- 选中组节点后，在「对齐 / 分组」菜单里点「生成组内图片」，会自动收集组内图片节点（`metadata.groupId`）。
- 复刻配图的整组生成由 Agent 的 `generate_remix_images` 触发，只圈定本次复刻生成的配图，不会带素材原图；策划未就绪时拒绝生成。
- 空提示词的图片节点不会入队：全部不合格时提示「都没有提示词」且不发起任何请求、不扣算力点；混选时提示「已跳过 N 个」并只生成有提示词的那些。
- 批量等待只认本次生成新建的下游节点，你独立起的下游改图/视频不会拖住本张计数，也不会把它的失败记到本张头上。
- 开始前会二次确认，显示数量、图片模型和预计算力点；生成时显示当前第 N/M 张、成功/失败数和「停止全部」。
- 批量生成按顺序逐张执行，单张失败不会阻塞后续；停止只停当前和排队任务，已完成的结果保留。
- 每个图片节点只生成 1 张，避免当前全局数量设置让一个节点出多图，也保持素材图与复刻配图一一对应。

## 发布节点（抖音图文扫码）

发布节点用于把画布里的文案和图片组合成一次抖音图文发布；它不参与生成，只负责收集、预检和签发扫码内容。

### 创建与连接

- 通过画布底部工具栏“更多 → 发布”创建，或在画布空白处双击“添加节点 → 发布”。
- 发布节点只接受上游连入，不能从发布节点连线到其他节点。
- 把 1 个文案节点和想发布的图片节点连到发布节点即可；连了哪些图片，发布时就只能选哪些图片。

### 生成发布二维码

- 双击发布节点打开面板，直接编辑要发布的标题、正文、话题；面板只展示已选发布图片，可排序/移除，未选图片收在「添加上游图片」折叠区。
- 发布面板为「表单主列 + 220px 二维码列」：宽屏表单在左、二维码在右，窄屏或低缩放先表单后二维码；表单与二维码都是平铺分区，不再套内层卡片，二维码列在宽屏用左分隔线。
- 节点卡片是唯一图文预览，面板不再重复一份手机预览；预览仅示意，不能替代抖音编辑页。
- 已选发布图片支持拖拽排序：桌面直接拖动缩略图，触屏使用缩略图下方的上移/下移按钮；顺序会同步到预览、上传和最终发布。
- 素材源/发布节点默认 520×380；素材源解析出首图后按图片宽高比自适应尺寸（竖图得到竖版窄卡），尺寸仍是默认值时自动适配一次，手动调过尺寸后不再覆盖，重新解析换图会按新首图重新适配。
- 素材源卡片用单张大图轮播展示素材图（左右切换、页码），保留标题与作者互动数据；双击节点是打开面板的统一入口，卡片不再另放打开面板按钮。正文/话题等完整内容在面板查看。
- 二维码区标题为「二维码」，与面板标题区分；大二维码、有效期、回填作品链接和标记发布都在面板右列。
- 点“生成二维码”后，前端会把选中的图片转存到当前发布域名的 /api/publish/media/，再调用预检和签发。
- 预检不通过时会直接显示中文原因；常见限制：标题不超过 20 字、正文不超过 1000 字、话题不超过 5 个、图片 1–35 张、单张不超过 20MB、仅支持 JPG/PNG、短边不小于 360px、比例在 1:2.2～2.2:1 之间。
- 二维码有效期 2 小时；用抖音 App 扫码后进入抖音编辑页，图片、话题（以及可携带的标题）会带过去，用户确认发布。
- 图片多时二维码会比较密，点“放大二维码”用全屏大图扫码；过期后二维码会置灰，需要重新生成。
- 图文只能进入抖音编辑页，不能做到服务端静默直发；发布完成后可在面板里回填作品链接并标记“已发布”。

### 配置与联调

- 后台“私有配置 → 抖音发布”配置 publicBaseUrl、抖音 Client Key / Client Secret，并可点“测试抖音配置”验证 client_token / open/getticket 权限。
- publicBaseUrl 必须与用户访问画布的域名一致，例如 https://jl.lx.cq.cn；发布图片保存在服务器本地发布目录，通过该域名的 /api/publish/media/ 提供公网 HTTPS 访问，不依赖 OSS。
- MOCK 模式用于权限未联调或本地验证：二维码格式与签名规则相同，但抖音不会接受，不能当成真实发布。
- 发布依赖抖音开放平台 H5 分享能力（h5.share、open.get.ticket，以控制台实际申请项为准）；图片必须能被抖音服务器公网回源抓取。

## 漫画册节点

漫画册节点把多张图片合成一本可翻页预览的漫画，负责贴字与成品导出；企划、设定、剧本、页格与整页拼合在漫画工作台 `/comic`。

### 创建与页面管理

- 通过画布底部工具栏「更多 → 漫画册」创建空漫画册，也可以在画布空白处双击，在「添加节点」菜单里选择「漫画册」；或选中 ≥2 张图片后点工具栏「合集」。合集按画布位置 y→x 排序，节点放在图片组右侧并自动打开预览。
- 节点卡片是轻量工作台状态卡：显示封面、最多 3 个页面槽位缩略图、画布册页数、格式/方向、关联项目阶段与合成/审稿进度、缺页状态；按状态提供一个主动作、直接贴字和更多操作。缩略图可定位并选中对应页面，选中漫画册会高亮有效页，选中页面会反向高亮引用它的漫画册。
- 双击漫画册打开全屏预览；卡片主动作按当前状态执行加入选中图片、处理缺页、继续布局、继续审稿或打开漫画册。页面关系保存在节点 `metadata.comicBook.pageNodeIds`，不为每页额外建连线。
- 预览内支持缩略图拖拽排序、移除页面、设封面，以及把当前选中的图片节点加入；缺失页面保留原页序槽位，可移除引用或用当前选中的未引用图片替换，替换会迁移封面、项目映射和贴字。

### 预览

- 页漫：单页/双页切换，右→左或左→右阅读方向，方向键与左右滑动翻页，切换页面带 3D 翻页过渡。
- 条漫：竖向连续滚动。

### 贴字

- 页漫单页模式下开启「贴字」，可添加对白、思考、旁白、拟声四类气泡并拖拽定位。
- 检查器可改文本、模板、宽度、字号、对齐、尾巴方向与尾巴位置；「适配文字宽度」按文字长度收敛气泡宽度。
- 模板为椭圆 / 圆角 / 方框 / 云朵 / 旁白条，默认按类型取模板：对白椭圆、思考云朵、旁白旁白条；云朵是虚线气泡加两个圆点尾巴。
- 贴字按页面存在 `comicBook.lettering`，预览与导出共用同一套模板、内边距和尾巴位置。

### 导出

- CBZ：PNG 序列 + `ComicInfo.xml`。
- PDF：首图比例 150dpi，或 A4/B5 300dpi，等比 contain 留白边。
- 条漫长图：1080px 宽，总高超过 16000px 时提示改用 CBZ/PDF。
- 齿轮按钮配置页面尺寸、DPI、页码与扉页标题，设置存 `comicBook.exportPreset`；页码与扉页烘焙进 CBZ/PDF/长图，扉页不计页码，页面尺寸只影响 PDF。
- 导出时把气泡、文字和拟声词烘焙进页面 PNG，条漫预览也会叠字。

### 与漫画工作台同步

- 漫画册的「项目操作」可选择本机漫画项目：「仅关联项目」只写 `comicBook.comicProjectId` 和 `pageProjectIds` 页映射，不改变贴字、页序、封面或导出设置。
- 「同步贴字」是独立动作，按已有页映射把项目页格里的对白、旁白、拟声写入漫画册，确认框会显示未映射和覆盖统计；没有对白/旁白/拟声的项目页保留已有贴字。页数不一致只对应前 N 页。
- 工作台页头「画布同步」可把已合成整页发送为画布图片页与漫画册；再次发送时按 `comicProjectId` 更新已有漫画册，按页序复用页面节点并保留位置、封面与已有贴字，新增页追加，减少的页只移出漫画册。
- 「从画布回写」按 `comicBook.pageProjectIds`（画布页面节点 → 工作台页面）把贴字写回页格：对白/思考 → 对白，旁白 → 旁白，拟声 → 拟声，只覆盖有贴字的字段；页序只调整同章节内顺序，跨章节移动不回写，被改写的页面退回草稿。缺少页映射的旧漫画册会提示先发送/更新一次。
- 复制/粘贴漫画册与其页面图片时，`pageNodeIds`、封面、贴字页面键和 `pageProjectIds` 会映射到新图片节点；只复制漫画册本身时保留原页面引用。
