# 漫画册画布工作台节点设计

## 状态

设计已由用户确认，尚未实现。本文只定义画布漫画册节点的职责、状态和交互，不构成实现完成声明。

## 背景

画布漫画册节点目前展示封面、页面数、格式和“预览”按钮。页面排序、封面管理、贴字、项目关联、贴字同步和成品导出主要集中在打开后的大面板中，因此漫画册在画布上看起来更像一个带封面的静态结果节点，难以看出可以继续进行的工作。

目前存在两个独立数据域：

- 画布项目中的 `CanvasComicBook` 保存页面节点引用、封面、格式、方向、贴字、导出预设和漫画项目映射。
- 漫画工作台的 `ComicProject` 保存企划、角色、场景、章节、页格、审稿状态及合成页图，并由本机漫画 store 持久化。

画布册和项目的分离是有意的：漫画工作台负责前制与页格生产，画布漫画册负责页面编排、贴字和最终导出。本设计保留这个边界，不把项目内容复制进画布节点，也不增加第二个漫画编辑器。

## 目标

- 让漫画册在画布中呈现为可继续工作的成品节点，而不只是封面图片。
- 让用户快速看清画布册实际包含的页面、格式、阅读方向、项目阶段和下一步动作。
- 利用画布空间关系，让漫画册与其页面图片相互可发现、高亮和定位。
- 保持画布页面资产独立可连接、替换、复制和复用。
- 将项目关联和贴字同步拆成两个明确操作，避免关联时意外覆盖贴字。

## 非目标

- 不在节点卡片内实现页格编辑器、页面拖拽排序或完整项目编辑。
- 不复制漫画工作台的企划、角色、场景、剧本、页格生产和审稿界面。
- 不新增第二套贴字参数、成品导出实现或导出预设。
- 不创建漫画册与每页之间的重复 `CanvasConnection`。
- 不因项目暂不可用或页面图片被删除而自动解绑项目或静默移除页面引用。

## 节点卡片

卡片沿用画布主题和现有节点外观，不把节点变成大型应用面板。信息按稳定层级展示：

1. 标题与状态标签，例如“页布局 · 6/8 页已合成”。
2. 封面与最多 3 张页面缩略图；更多页面显示剩余数量。
3. 画布册元信息：有效页面数、页漫/条漫、阅读方向。
4. 仅当本机存在已关联漫画项目时显示项目进度；画布册页数与项目页数分开呈现。
5. 一个随状态变化的主动作，最多两个次动作。

双击节点或点击“打开漫画册”仍打开现有漫画册面板。缩略图不提供拖拽排序；页面顺序仍在现有漫画册面板中维护。

### 快捷动作

- `打开漫画册`：打开现有漫画册面板。
- `直接贴字`：打开同一面板并直接进入贴字模式，不创建第二个贴字编辑器。
- `打开项目`：跳转到已关联的漫画工作台项目。
- `继续拼合`：项目处于页布局阶段且存在未合成页时，打开该项目现有页布局阶段。
- `继续审稿`：项目处于审稿阶段且仍有未通过页面时，打开该项目现有审稿阶段。
- `处理缺页`：打开现有漫画册页面管理，不自动删除失效引用。
- `关联项目` / `重新关联`：只维护项目 ID 和页面映射，不触发贴字同步。
- `同步项目贴字`：独立的显式操作，保留现有二次确认语义。

阶段跳转沿用项目当前持久化的 `stage`，不为节点快捷入口临时改变或覆盖项目阶段。

## 状态模型

节点状态由画布册引用、本机漫画 store hydration 状态和可选的本机项目数据推导，不写回为重复的派生状态。

### Loading

漫画 store 尚未 hydration 时，项目关联区域显示“正在读取漫画项目”。不得提前显示“项目不在本机”。画布册自己的页面引用仍可用于渲染封面和页数。

### Empty

`pageNodeIds` 为空时显示“漫画册还没有页面”。提供加入当前选中图片和打开漫画册入口。未选中图片时，加入操作禁用并说明先选择画布图片。

### Standalone

没有 `comicProjectId` 时，显示画布册自己的有效页面数、格式和方向，不显示项目阶段或项目进度。提供打开漫画册、直接贴字和关联项目入口。

### Linked

漫画 store hydration 完成且找到对应项目时，显示项目阶段和该阶段的有效进度：

- 页布局阶段：项目已合成页数 / 项目总页数。
- 审稿阶段：项目已通过页数 / 项目总页数。
- 企划、设定、剧本阶段：只显示阶段，不伪造百分比。

项目进度与画布册页数是不同统计。例如“画布册：6 页”和“项目：8 页，6 页已合成”可以同时出现，不能合并成一个总数。

主动作按当前项目阶段选择：有未合成页时为“继续拼合”；审稿阶段仍有未通过页面时为“继续审稿”；其他情况为“打开漫画册”。

### Project Missing

漫画 store 已 hydration，但 `comicProjectId` 对应项目不存在时，显示“关联项目不在本机”。保留原 `comicProjectId` 和 `pageProjectIds`，漫画册仍可独立打开、贴字和导出。用户明确选择另一个项目后才替换关联。

重新关联不得自动覆盖贴字、页面顺序或导出预设。已有其他项目关联时，替换关联前需明确确认；确认只授权替换项目 ID 和映射。

### Missing Pages

有效画布页面定义为 `pageNodeIds` 中可找到、且含可展示图片内容的图片节点。缺失数等于引用 ID 数减有效页面数。缺失引用显示为占位缩略图并提示数量；不自动删除引用或重排页面。

画布页面数只统计有效图片页面；项目页面数从关联项目章节汇总。两种数字分别标注来源。

## 画布高亮与缩略图定位

画布关系高亮从“显式连线”扩展为“显式连线 + 漫画册页面引用”，但数据关系仍由 `comicBook.pageNodeIds` 保存，不产生新连线。

- 漫画册处于选中或活动焦点时，高亮漫画册及其有效页面图片节点。
- 页面图片处于选中或活动焦点时，反向高亮引用该页面的漫画册，并高亮同册有效页面。
- 漫画册卡片缩略图可点击；点击后调用画布现有页面聚焦能力，使对应图片节点进入视口并被选中。通过现有反向关系高亮，漫画册与同册页仍保持可见关联。
- 缩略图点击不改变 `pageNodeIds` 顺序、不设封面、不修改贴字。
- 页面定位必须遵循现有画布定位行为，并保留键盘可达性与可见焦点。每个缩略图提供包括页码和标题的可访问名称。

## 项目关联与贴字同步

### 关联项目

关联操作与贴字同步分开：

1. 用户选择一个本机漫画项目。
2. 页面映射以当前漫画册 `pageNodeIds` 顺序和项目章节页序建立，映射到两边较短的一侧。
3. 保存 `comicProjectId` 与 `pageProjectIds`；不更改页面顺序、`lettering`、封面或导出预设。
4. 页面数量不一致时明确显示已映射页数及未映射页数。

这是显式关联操作；若替换已有的不同项目，确认文案必须说明旧项目映射会被替换、已有贴字和画布册页面不会被覆盖。

### 同步贴字

- 仅由“同步项目贴字”动作触发，并保留确认步骤。
- 使用 `pageProjectIds` 将工作台页面与画布图片页对应；不再仅依赖两个列表当前索引相同。
- 确认前显示将同步的页面数量、无法映射的页面数量，以及是否会覆盖已有贴字。
- 取消不修改漫画册数据；确认后只更新贴字及必要的项目映射，不改页序、封面和导出预设。
- 画布贴字回写继续沿用现有 `pageProjectIds` 映射及已定义的审稿状态回退规则。

## 组件与数据边界

- `CanvasComicBookNodeCard` 负责漫画册状态卡、缩略图和节点内快捷动作。
- `CanvasStageLayer` 将漫画册节点引用解析为页面节点，并提供定位、打开漫画册、打开漫画项目和进入贴字模式回调。
- `CanvasClientPage` 扩展现有关系高亮集合，把页面引用关系纳入节点关联高亮；不生成持久化连线。
- `CanvasComicBookOverlay` 继续负责页面顺序、封面、贴字、预览和导出。通过明确的初始模式参数支持从卡片直接进入贴字模式。
- 漫画项目阶段及统计从 `useComicStore` 和现有漫画项目纯函数读取；漫画册状态解析保持为可单测的纯函数。
- `CanvasComicBook` 不新增项目阶段、合成计数等派生字段。

## 异常与边界

- 漫画 store 加载中不得把项目标成不存在。
- 项目不存在时不清理任何关联 ID，也不阻止漫画册独立操作。
- 删除页面图片后保留引用并展示缺页；修复必须由用户在页面管理中完成。
- 复制漫画册和页面时沿用现有 ID 重映射行为；只复制漫画册时继续保留原页面引用。
- 项目导入、删除或切换账号后，卡片按当前 store 重新推导 linked/project-missing 状态，不修改画布册内容。
- 低缩放下延续画布已有节点可读性规则；高亮不能盖住节点正文或抢占节点拖拽操作。

## 验收标准

1. 空册、独立漫画册、本机已关联项目、关联项目缺失、引用页面缺失均显示正确状态和动作。
2. 项目 loading 期间不闪现“关联项目不在本机”。
3. 卡片分别显示有效画布册页数与项目总页数/阶段进度，语义和计算口径清楚。
4. 选中/活动漫画册高亮所属页图；选中页图反向高亮漫画册及同册页；不产生额外连接数据。
5. 点击缩略图定位并选中对应页面；不会更改漫画册页序或封面。
6. 关联/重新关联不触发贴字同步，不覆盖已有贴字、页序、封面和导出预设。
7. 贴字同步单独确认，按 `pageProjectIds` 映射，并清楚报告覆盖和未映射数量。
8. 现有面板的贴字、预览、翻页、导出及导出设置保持可用。
9. 复制漫画册、删除引用页图、缺页修复、窄屏和低缩放行为经过浏览器回归。
