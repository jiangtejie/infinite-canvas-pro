# 影视 Studio 独立入口与舞台壳层设计（批次 1C）

> **已被取代（2026-11-22）**：Studio 壳层、左栏镜头设置、胶片条、时间轴与旧视图切换已由 [Film Director Board 设计](2026-11-22-film-director-board-design.md) 取代。当前入口是 Director Board + Shot Focus；本文仅保留“复用同一 CanvasProject、不新增 store/任务/引擎”的约束作为历史记录，不再作为 UI 实现依据。
>
> 状态：2026-11-21 已确认。本文是 [影视创作并入画布节点](2026-11-21-film-as-canvas-design.md) 的追加设计。
> 主 spec 的数据模型、边语义、资产体系、同步与批次 0-3 目标不变；本文只调整**影视默认入口与壳层交互**：独立入口，引擎继续复用，Studio 成为影视默认视图。
> 参考 [GPT-anime-denoise-web](D:\SoftwareData\自媒体画布工作台\GPT-anime-denoise-web) 的舞台式结构（全幅 stage、左侧设置面板、底部胶片条、浮动控件、键盘优先、极简 chrome），不借它的单图去噪引擎。

## 目标

1. 影视有独立入口 `/film/studio/[id]`，不再从 `/canvas/[id]` 进入。
2. 默认是**单镜舞台 + 胶片条**：全幅舞台显示当前镜头，底部胶片条切换镜头，左侧固定镜头设置，顶部极简。
3. 交互参考 GPT 的舞台式体验：大画面、少卡片、浮动控件、键盘优先、明暗主题一致。
4. 引擎完全复用：同一份 `CanvasProject`、同一套节点/连线/任务/同步/资产；不新增 store、任务或画布引擎。
5. 画布图退成 Studio 内的「画布」视图，用于结构编排与资产节点编辑。

## 非目标（1C 不做）

- 不接生成、对比、版本、槽位编辑器（批次 1B）。
- 不做镜头表/故事板板/时间轴/批量/AI 拆镜（批次 2）。
- 不删除旧 `/film/[id]` 工作台（批次 3）。
- 不复制 GPT 的图片画笔/遮罩/去噪引擎，不做第二个节点画布。

## 一、入口与路由

- 新增 `web/src/app/(user)/film/studio/[id]/page.tsx`，渲染共享的 `CanvasEditor`（`studio` 模式）。
- `/film` 成为影视主入口：
  - 新增「影视画布」区（`FILM_CANVAS_DEV` 后可见）：列出画布 store 中 `domain === "film"` 的文档，打开 `/film/studio/[id]`。
  - 新增「新建影视画布」按钮：`createFilmProject` 后进入 `/film/studio/[id]`。
  - 旧工作台项目继续显示在原列表，与「影视画布」分区展示；批次 3 统一。
- `/canvas` 移除 1A 的影视开发入口与影视画布列表，只保留通用画布；影视不再从 `/canvas` 进入。
- `/canvas/[id]` 打开影视文档时重定向到 `/film/studio/[id]`；`/film/studio/[id]` 打开非影视文档时重定向到 `/canvas/[id]`。用 `studio` 标志 + `domain` 双重判断，避免循环。
- `/film/[id]` 旧工作台保留到批次 3；批次 3 删除工作台后，`/film/[id]` 重定向到 `/film/studio/[id]`，Studio 路由作为正式入口保留。

## 二、共享编辑器与壳层切换

- 把 `web/src/app/(user)/canvas/[id]/canvas-client-page.tsx` 重命名为同目录 `canvas-editor.tsx`，导出 `CanvasEditor`：
  - `canvas/[id]/page.tsx` 渲染 `<CanvasEditor />`。
  - `film/studio/[id]/page.tsx` 渲染 `<CanvasEditor studio />`。
  - 只做文件/导出边界调整，不重写运行逻辑；当前只有画布页引用该文件。
- `CanvasEditor` 继续构建唯一的 `CanvasWorkspaceModel`；新增可选 `filmStudio` 模型传给 `CanvasWorkspace`。
- `CanvasWorkspace` 增加可选 `filmStudio`：
  - `view === "studio"`：渲染 Studio 主体（左设置栏 + 舞台 + 胶片条），不渲染通用侧栏、Agent 面板与画布舞台层；仍渲染 `CanvasTopBar` 与 `CanvasDialogs`。
  - `view === "graph"`：保持现有画布壳层（侧栏、舞台、覆盖层、Agent、检查器）。
  - 顶栏共用；Studio/画布切换是浮动 pill，不新增第二条顶栏。
- 顶栏 `CanvasTopBar` 增加影视可选能力：
  - 场次选择：标题右侧紧凑 `Select`，数据来自 `filmStudio.scenes`。
  - `onProjects` 在影视模式指向 `/film`；菜单「新建画布」在影视模式显示为「新建影视画布」。
  - 「按场整理」只在画布视图显示。
- 视图状态与当前镜头是 UI 状态，不写入文档；默认 Studio。切到画布再切回，保留当前镜头与场次。

## 三、Studio 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：返回影视 / 标题 / 场次选择        保存 · 主题 · 菜单     │
├──────────────┬───────────────────────────────────────────────┤
│ 镜头设置      │               舞台（全幅）                     │
│ 基础          │   16:9 分镜画面 / 空镜卡 / 生成后预览          │
│ 画面          │                                               │
│ 上下文        │        [Studio | 画布] 浮动切换                │
├──────────────┴───────────────────────────────────────────────┤
│ 胶片条：第1集·场景1 [01][02][03]+  场景2 [04][05] ...         │
└──────────────────────────────────────────────────────────────┘
```

### 顶栏

- 沿用 `CanvasTopBar`：返回/菜单、标题、保存状态、主题、快捷键、账号、Zen、助手。
- 标题右侧显示当前场次 `Select`（如「第 1 集 · 场景 1」），切换场次时聚焦该场第一个镜头。
- 舞台顶部中央浮动 `Studio / 画布` 切换 pill；画布视图同样显示，位置不遮顶栏。
- 影视模式下 `onProjects` → `/film`，新建 → 新影视画布并进入 Studio。

### 左栏：镜头设置

- 固定宽度约 320，可折叠；移动端为浮层（设置按钮开合）。
- 分节细线、不做嵌套卡片、短标签、大控件，使用 `canvasThemes` token。
- 区块：
  1. 镜头：镜号、景别、时长、运镜。
  2. 画面：描述、画面提示词、负面提示词。
  3. 上下文：绑定角色/场景/道具/风格只读 chips（来自 binding 边）；无绑定显示「未绑定」。
  4. 状态：出图/出视频/过期（1B 接真实状态）。
- 字段写回镜头节点；与画布检查器共用 `film-node-patch` 更新函数，避免两套补丁逻辑。

### 舞台

- 全幅；按 `film.aspect` 显示画面框。
- 有分镜图时显示图片；没有时显示干净的「空镜卡」：大镜号、场次、描述/提示词摘要；不放假生成按钮，1B 再接生成。
- 顶部左：场次/镜号面包屑；右上：状态；底部：上一镜/下一镜按钮与 `←/→` 提示。
- 「在画布中定位」：切到画布视图并选中/居中当前镜头（切换后延迟聚焦）。
- 1B 在舞台内补对比/版本/适配/生成浮动工具条。

### 胶片条

- 底部横向滚动；按场分组，场标题 + 镜头卡片；卡片显示镜号、状态点，1B 加缩略图。
- 当前镜头高亮并自动滚入视野；点击或 `←/→` 切换。
- 每组末尾 `+`：在当前场次追加镜头（自动建 `composition` 场次边 + `sequence` 序列边，设置镜号）。
- 无场次时提示「去画布创建场次」；不静默失败。

### 键盘与响应式

- `←/→` 上一镜/下一镜；`Tab` 在胶片条/左栏/舞台间移动；`Esc` 退出缩放/浮层。
- 1B 再加 `F` 适合、`C` 对比、`G` 生成。
- 窄屏：左栏变浮层，胶片条高度收紧，舞台优先；不在移动端堆双栏。

## 四、数据与复用边界

- 不新增 `FilmProject`、store、任务或同步；Studio 只读写同一份节点/连线。
- 新增纯函数模块（带单测）：
  - `canvas/[id]/lib/film-selectors.ts`：场次分组、镜头排序（复用 `orderSceneShots`）、未分场组、当前镜头回退、镜头绑定资产。
  - `canvas/[id]/lib/film-node-patch.ts`：剧本/场次/镜头/资产节点补丁；左栏与画布检查器共用。
  - `canvas/[id]/lib/film-shot-create.ts`：在指定场次追加镜头，生成节点 + composition/sequence 边 + 下一镜号。
- Studio 主体组件放在 `canvas/[id]/components/`（与画布编辑器同域），避免影视页反向依赖画布内部细节：
  - `film-studio-body.tsx`（布局）
  - `film-shot-panel.tsx`（左栏）
  - `film-shot-stage.tsx`（舞台）
  - `film-strip.tsx`（胶片条）
- `CanvasWorkspace` 只增加一个条件分支：Studio 主体或现有画布主体；不复制侧栏/舞台/任务逻辑。
- 画布图视图继续复用现有 `CanvasWorkspace`、`CanvasStageLayer`、`CanvasFilmInspector`；画布检查器保留。

## 五、1C 范围与验收

### 范围

1. 路由：`/film/studio/[id]`、`CanvasEditor` 抽取、影视/画布互相重定向。
2. 入口：`/film` 影视画布区与新建；`/canvas` 移除影视开发入口。
3. 纯逻辑：`film-selectors`、`film-node-patch`、`film-shot-create` + 单测。
4. Studio 壳层：顶栏场次选择、浮动视图切换、左栏、舞台空镜/有图、胶片条、镜头追加、键盘、响应式。
5. 画布视图回归；刷新持久化；移动端基本可用。

### 验收

- 从 `/film` 新建/打开影视画布 → 默认 Studio；顶栏场次选择可用。
- 胶片条切换镜头，舞台与左栏同步；左栏编辑刷新后保留。
- `+` 在当前场次追加镜头；胶片条/舞台更新；切到画布能看到 composition/sequence 边。
- `Studio / 画布` 切换保留当前镜头；画布视图现有节点/检查器/按场整理不回归。
- `/canvas` 不再出现影视入口；`/canvas/[id]` 影视文档重定向到 Studio。
- `bun test`、`typecheck`、`lint` 通过；浏览器实测无 console 错误；测试画布清理。

## 六、风险与对策

- **大文件抽取**：`CanvasEditor` 只做文件边界与 `studio` 标志，不改运行逻辑；抽取后先跑画布回归。
- **重定向循环**：用 `studio` 静态标志 + 项目 `domain` 双向判断；项目加载完成后再重定向。
- **双入口**：1C 就移除 `/canvas` 影视入口；旧 `/film/[id]` 与新 Studio 分区展示，批次 3 收口。
- **双补丁逻辑**：左栏与画布检查器共用 `film-node-patch`，不在组件里各写一份。
- **长片性能**：胶片条按场分组、当前镜自动滚入；选择器 memo；1C 不做虚拟列表，批次 2 视实测再优化。
- **生成前空舞台**：空镜卡明确「生成后显示画面」，不放假按钮/假数据。
