# 待测试

## 登录页精简

- 登录页去掉“支持账号密码和 Linux.do 登录”说明文字、Linux.do 登录按钮和 OAuth 回跳处理，仅保留账号密码登录与注册；需验证登录、注册、切换标签和错误提示。
- 后台设置移除“Linux.do 登录”配置卡片（开关、Client ID / Secret、OAuth App 链接）和对应默认值；后台用户列表移除 Linux.do 列，搜索不再匹配 Linux.do ID；需验证设置页其它配置保存后不变、JSON 模式下不再写出 linuxDo 字段。
- 后端删除 Linux.do OAuth 接口（`/api/auth/linux-do/*`）、鉴权逻辑、用户字段、配置项和对应测试；需验证账号密码登录、注册、JWT 续期正常。
- 本地开发库已物理删除 `users.linux_do_id` 列及其索引；其他环境的旧库需先 `DROP INDEX idx_users_linux_do_id`，再 `ALTER TABLE users DROP COLUMN linux_do_id`。
- 清理前端遗留的死代码：图片页的日志键与分类合并辅助函数、视频页未使用的快照构建函数、Kling 工作台的秒数归一化函数，以及三处失效的图片标签导入；需验证图片/视频工作台生成、历史、Kling 工作台参数均正常。

- 后台提示词详情去掉“远程源”按钮，同步远程提示词源弹窗去掉每行远程源的跳转图标；需验证详情弹窗、同步弹窗和远程源列表展示。

- 输入框下新增“设计一张封面”“策划视频分镜”“梳理创作灵感”示例入口，点击后填入内容并聚焦输入框；已有内容保留并追加，不自动提交；需验证光标位置、素材引用、Skill 保留及手动发送。
- Banner 缩小桌面尺寸、倾斜角度和阴影，调整居中布局，扩大切换指示器点击区域并补充焦点、选中状态及减少动画支持；需验证拖拽、左右切换、键盘操作、外链与视频播放。
- 提示词区改为左对齐标题和右侧入口，区分站内提示词库与外部仓库；统一卡片圆角、文字遮罩和标签样式，采用手机单列、平板双列、桌面四列布局；需验证长标题、长标签、图片懒加载和预览顺序。

## 工作台展示层与错误结构统一

- 图片和视频结果卡改为共享组件：提示词块、参数标签、媒体信息条、参考图角标、失败卡结构保持一致；需验证新生成、生成中、失败、历史记录四种状态以及浅色/深色配色。
- 失败卡统一为"生成失败 + 详情 + 重试"，历史记录卡在参数区下方显示错误行并保留"详情"入口；需验证详情弹窗内容、滚动和关闭后的焦点回到触发按钮。
- 工作流任务失败卡新增"重试"和失败详情弹窗，重试沿用原任务的提示词、变量、参考素材和数量重新提交；需验证失败任务重试、成功后不再显示重试、工作流被删除时的提示。
- 提示词库请求失败时改为页面内错误状态并提供"重试"按钮，不再只弹一次轻提示；需验证断网、恢复网络后重试，以及错误态与"没有匹配提示词"空态的区分。
- 生图、视频、工作流路由新增加载骨架和加载失败重试页，动态加载工作流、Kling 工作台的占位也改为统一加载态；需验证首次进入、路由切换、后端不可用时的错误页和恢复。
- 图片与视频工作台的底部输入区、侧边提示词区、参考素材条改为共享组件，参考素材条统一支持滚轮横向滚动；需验证侧边/底部布局切换、上传、移除、排序和空态文案。
- 结果区头部按钮组在窄屏下改为换行排列；需验证手机宽度下"全选/下载/删除/分类"等按钮不溢出。
- 画布侧边栏素材卡支持点击（或键盘 Enter/空格）直接插入画布，拖拽行为保持不变，窄屏插入后自动收起侧边栏；需验证素材、素材库两类卡片。
- 画布支持双指缩放、双指平移，以及选择工具下空白处单指拖动平移；需验证缩放锚点、最小/最大缩放、与节点拖拽和滚动区域的手势冲突。
- 画布移动端侧边栏使用动态视口高度并限制内部滚动穿透；需验证横竖屏切换、面板内列表滚动和遮罩关闭。
- 全站补充键盘焦点样式、`prefers-reduced-motion` 下的动画降级、生成中状态播报，以及历史卡片图标按钮的可访问名称；需验证 Tab 键焦点可见性、系统开启"减弱动效"后的表现和读屏播报。
- 图片与视频结果区改用共享容器组件（标题、数量、生成中播报、新建/全选/下载/删除按钮组），图片的"全部展示/分类展示/返回分类"仍由页面提供；需验证分类视图、批量选择、批量下载和删除。
- 画布右键菜单支持键盘操作：打开即聚焦第一项，上下方向键循环、Home/End 跳转、Esc 关闭并回到原焦点；节点提示词面板关闭后焦点回到节点本身；需验证鼠标与键盘混用、菜单在窗口边缘的定位。
- 画布图片、视频、音频参数浮层支持 Esc 关闭并把焦点送回触发按钮，下拉框展开时按 Esc 只关下拉框；需验证浮层内下拉、滑块、输入框与 Esc 的交互顺序。
- 开发模式下视频页与工作流页会把首屏挂载耗时写入 `window.__screenTimings`，超过 2.5 秒时在控制台告警；需验证开发模式无异常、生产构建不产生该输出。

- 各用户端路由新增独立页面标题，并统一为“页面名 | 无限画布”的浏览器标题格式；需验证画布库、生图、视频、工作流、提示词、素材、素材库和登录页面标题。
- 用户端页面、登录页、顶部导航、移动端导航、配置弹窗、版本弹窗、提示词/素材弹窗及共享组件已统一改用语义颜色 token，不再使用硬编码 `stone-*` 色阶；需验证浅色/深色主题下文字对比度、边框、悬停态、错误详情和空状态。
- 工作流页面、生图页工作流抽屉和视频页 Kling 工作台改为按需加载，并显示加载占位；需验证首次打开、抽屉展开、Kling 模型切换以及加载失败后的恢复。
- 生图、视频和 Kling 工作台的标题与“侧边/底部”布局切换抽取为共享组件，三个入口的视觉和交互保持一致；需验证切换布局后偏好回填和标题显示。
- 提示词库、我的素材、素材库、素材选择器和提示词选择器统一使用共享筛选标签组件，生图、视频和 Kling 工作台统一使用共享快速参数控件；需验证分类、标签、质量和数量选择的筛选和回填结果。
- 提示词库、我的素材、素材库、画布库、图片/视频结果区、素材选择器和嵌入式工作流统一使用共享加载/空状态组件；需验证加载文案、空状态说明和按钮位置。
- Ant Design 全局字体、圆角和链接色改为与应用主题一致；素材页增加“素材库”入口，工作台和结果卡片的图标按钮补充可访问名称；需验证控件尺寸、焦点和浅深色显示。
- 画布窄屏下侧边栏和 Agent 面板改为固定覆盖层，带遮罩和关闭操作；打开一侧时自动收起另一侧，窄屏默认收起侧边栏；需验证打开/关闭、遮罩点击、面板内操作，以及桌面端双栏布局不变。

## 画布交互与反馈优化

- 缩放区新增“查看全部”，点击缩放百分比可选择“聚焦选中”和“100%”；支持 Shift + 1 / 2 / 0。定位按当前画布区域计算并为顶部和底部控件留白；需验证左右侧栏展开/调宽、空画布、多选、折叠批次、远距离节点、窄屏及恢复已有画布视角。
- 节点搜索和助手定位复用新的居中逻辑，适配“减少动态效果”偏好，手动缩放或拖动画布时中断定位动画；需验证连续定位与手动操作衔接。
- 按住空格始终临时移动画布，松开恢复原工具；输入框、按钮、菜单及弹窗保持自身空格行为。外观面板新增鼠标/触控板偏好并记忆选择，鼠标滚轮缩放、触控板双指滚动平移，Ctrl / ⌘ + 滚动或直接捏合缩放；需验证编辑文字、键盘按钮、双指手势和浮层内部滚动互不干扰。
- 工具栏保留常用创建入口，全景图、导演台、生成配置归入“更多”，素材库与我的素材合并为“素材”；“清空画布内容”移至顶部画布菜单并保留二次确认，删除选中仍保留；需验证菜单键盘操作、窄屏滚动和各入口原功能。
- 顶部栏与缩放区统一打开同一个快捷键弹窗，键帽跟随浅深色主题，修饰键按系统显示；助手入口弱化背景和阴影。需验证两处快捷键入口、关闭后焦点及主题切换。
- 画布名称支持单击、聚焦后 Enter/空格/F2 进入编辑，进入时选中文本，完成或取消后恢复标题焦点；需验证中文输入法、Enter 保存、Esc 取消和点击外部保存。
- 视频生成无有效进度时显示“处理中”和耗时，不显示 0% 进度条；正进度保留百分比。错误节点显示简短摘要、查看详情与重试，完整详情支持换行、滚动、复制、Esc 关闭及焦点返回，错误色跟随主题；需验证图片/视频/音频失败、长错误内容及重试和停止原逻辑。
- 本轮仅完成源代码改动与人工差异核对，未执行构建、语法检查、自动化测试或浏览器交互验证。
