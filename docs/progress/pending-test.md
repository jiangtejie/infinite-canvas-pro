# 待测试

## 创作框工具条弹层方向

- 创作框工具条上的四个入口——添加素材、Skill、图像设置（自动·1:1）、视频设置（720p·横屏）——统一改为优先向下展开；当按钮下方空间不足（例如画布底部助手面板）时自动翻转到上方，面板高度按可用空间收缩。
- 需验证：首页四个入口都向下弹出、下方空间不足时自动翻转、图像 / 视频设置面板内部滚动，以及在画布助手面板里打开时的方向。

## 创作框 Skill 面板

- Skill 面板改为固定定位并自动选择展开方向：下方空间足够就向下展开，否则向上，高度按可用空间收缩并在面板内滚动，不再被页面滚动容器裁掉或被顶栏遮住。
- 样式：标题 / 页签 / 搜索栏改为吸顶并带分隔线，面板加背景模糊以便压在横幅图上仍可读，去掉多余的横向滚动条。
- 需验证：首页、画布助手面板内的 Skill 面板展开方向、滚动、搜索与「我的」页签的导入按钮，以及窗口缩放后的重新定位。

## 首页创作框弹层

- 首页创作框的「添加素材」菜单与 Skill 面板、画布右下角缩放菜单、Codex 模式的模型 / 推理强度菜单均改为自绘弹层。原因：antd 的弹层依赖 rc-trigger 的入场动画完成后再定位，在「减少动态效果」或动画被压缩到 0.01ms 的环境里会一直停在上屏前的隐藏坐标，表现为点击无反应；自绘弹层直接贴合按钮定位，不受该机制影响。
- 需验证：点击后菜单出现在按钮上方、点外部/按 Esc 关闭、上传与素材入口正常、Skill 面板可滚动且编辑弹窗正常。

## 视觉统一

- 生图/视频结果卡、历史卡、工作流模板卡与结果卡的圆角统一为 12px（与画布库项目卡、浮层一致）。
- 后台 ProTable 统一：表头改用 `muted` 底色与次级文字色、行悬停用 4% 前景色、外框 12px 圆角；需验证用户/提示词/AI 日志三张表的表头对比度、行悬停与分页区域。

## 视觉细节二轮

- 输入框高度由 80px 收到 64px，示例胶囊的图标改为带 6% 前景底的圆形块，Banner 指示器当前项加了一圈暖色光晕。
- 新增 `neon-hover-border` 工具类：画布库项目卡、登录页卡片悬停/常驻时边框透出暖色霓虹；登录卡在深色下带渐变描边环。
- 需验证：深色下项目卡悬停是否过亮、登录卡渐变环在浅色下会不会显脏、以及输入框变矮后长提示词的滚动体验。

## 背景纹理

- 全站背景由「纯色 + 双光源」升级为四层叠加：颗粒噪点（SVG feTurbulence，160px 平铺）→ 细点阵（16px 间距，浅色 11% / 深色 12%）→ 左上冷光 → 右下暖光。
- 为了让纹理透出来，`(user)/layout.tsx` 的外壳（此前在这里把页面底色整个盖住）以及首页、提示词库、我的素材、素材库、画布库、登录页、404、生图/视频页的外层容器从 `bg-background` 改为透明，卡片与面板仍是不透明底。
- 需验证：浅色下点阵是否发脏、深色下噪点是否可见但不过噪，滚动时纹理是否稳定（点阵与噪点跟随内容，光晕固定），以及画布页（自身背景覆盖）不受影响。

## 首页霓虹改造

- 首页首屏新增冷暖双光源晕染（`neon-bloom`），主标题在深色下带暖色辉光，创作输入框外围换成「暖→冷」1px 渐变描边（`neon-ring`，用 mask 实现不占布局），三个示例胶囊改为 `neon-pill`：暗底细边、悬停透出霓虹描边。
- 光晕改为两团独立小光源（左 36%×240px、右 32%×220px，blur 38px），贴在输入框两侧而不是整屏铺满；背光收紧到 -10px / blur 20px；面板加顶部高光、内描边和外圈，形成双环；深色标题改为白→暖金渐变文字 + drop-shadow 辉光，占位文字不透明度 0.45 → 0.6。
- 需重点验证：深色下标题渐变是否仍清晰（光标已改为跟随 `foreground`，避免渐变文字把光标变透明）、浅色模式是否仍保持克制、以及输入框聚焦/粘贴素材时背光与描边的叠加效果。

## 页面级质感补齐

- 登录页与 404 页改为玻璃卡片承载内容，logo 增加辉光、404 数字改为渐变文字；需验证浅色/深色、窄屏高度（登录卡在手机上是否溢出）和表单聚焦态。
- 画布库项目卡新增节点缩略图预览（最多 3 张图片节点），并补悬停上浮、投影和图像轻微放大；需验证无图片节点的画布、缩略图裁切和点击进入。
- 生图/视频的结果卡与历史卡、工作流模板卡与运行结果卡统一补了悬停边框与投影（不做位移，避免卡内按钮抖动）；需验证列表滚动与点按手感。
- 移动端导航抽屉改为卡片式导航项：当前项带左侧强调条与图标底色块；需验证窄屏抽屉开关、图标对齐与深色下的对比度。
- 后台设置与 AI 日志里最后 3 处硬编码 `stone-*` 色阶改用语义 token；需验证浅色/深色下的输入框后缀、筛选框和详情代码块。

## 视觉质感层

- 全站页面底层加了双光源环境光（浅色/深色各一套 token，固定在 body 上，画布页面自身的背景会覆盖它）；浮层（底部创作栏、账户面板、画布工具条）改用新增的 `glass-panel` 亚克力层：顶部 1px 内高光 + 深投影。需验证浅色/深色下的层次感、浮层与背景的对比度，以及画布页面没有被环境光串色。
- 提示词卡片、我的素材、素材库卡片补了悬停微交互：整卡上浮 2px + 封面缓慢放大 1.03，过渡只走 transform / box-shadow；三个网格的首屏卡片按 40ms 错峰上浮入场。需验证悬停手感、图片裁切边缘、入场节奏，以及开启「减少动态效果」后是否直接出现。
- 画布侧栏与助手面板的节点状态圆点增加光晕（2px 半透明外环 + 8px 同色辉光）；Ant Design 分段控件的选中态改为内阴影描边。需验证深浅色下的可读性，以及分段控件切换时是否还有 1px 抖动。

## 账户入口样式

- 登录后顶部栏的账户入口改为「头像 + 下拉箭头」的紧凑按钮（不再显示用户名，悬停才出现边框和底色），下拉面板顶部为头像、用户名、账号标识与算力点胶囊，底部为退出登录；面板改为自绘实现，点击外部或 Esc 关闭。需验证浅色/深色、画布内顶部栏、管理员与普通用户、无头像账号，以及长用户名的截断。

## 前端细节优化

- 全站图片补齐 `loading="lazy"` / `decoding="async"`（列表、弹窗、画布缩略图），首屏不再一次性请求所有封面；需验证提示词库、素材库、我的素材、工作台结果和画布侧栏滚动时的图片加载表现。
- 新增顶层 `app/error.tsx`，并为画布库、画布详情、提示词库、我的素材、素材库、管理后台补充 `loading.tsx` 骨架；需验证路由切换时的占位效果，以及页面渲染报错后的「重试」。
- 7 处 `transition-all` 收窄为具体属性（进度条宽度、批量卡片位移与阴影、画布翻页按钮、粘贴按钮），减少不必要的属性过渡；需验证进度条动画、批量展开动画和按钮 hover 是否正常。
- 首页打字效果在「减少动态效果」下不再完全静止，改为放慢打字并取消光标闪烁；需验证两种系统设置下的表现。
- 修正首屏耗时诊断：客户端路由切换不再把「文档打开至今」当成首屏耗时，同一页面只告警一次。

## 首页打字效果

- 首页主标题改为轮播打字效果，循环「从一个想法开始创作 / 从一张参考图开始创作 / 从一段视频开始创作 / 从一句提示词开始创作」：逐字打出、停留 1.6 秒、逐字删除后切下一条；用最长一条做不可见占位，切换时不会布局跳动；开启「减少动态效果」时只显示第一条静态文案。需验证首屏观感、窄屏换行、切换衔接、长时间停留后的表现，以及读屏软件读到的标题文案。
