# 待测试

## 用户端 UI 统一优化

- 顶部导航移除当前不存在的“音乐创作台”入口，新增“工作流”入口；需验证桌面导航、移动端抽屉和活动态。
- 修复全局字体 token 循环定义，首页新增 AI 创作工作台标题和说明，将 Agent 创作输入置于 Banner 之前，并让 Banner 按视口居中；需验证首页素材上传、Skill、配置、提交、窄屏换行和 Banner 居中效果。
- 提示词库、我的素材、素材库移除重复点阵背景，统一使用语义背景、边框、弱化文本和空状态间距；提示词库标题由“提示词中心”改为“提示词库”；需验证浅色/深色主题、筛选、预览、导入导出和卡片操作。
- 图片与视频工作台统一使用共享布局偏好键，侧边栏宽度由固定 420px 调整为响应式 `minmax(280px, 360px)`；底部创作输入框改为主题语义背景和统一圆角；工作台外壳与参数控件使用语义边框；需验证侧边/底部模式、任务提交、轮询、结果历史和窄屏布局。
- 工作流独立页和嵌入式工作流统一为无厚重卡片的页面标题区，并移除页面内硬编码 `stone-*` 配色；需验证创建、筛选、执行、结果回写和抽屉入口。
- 画布工具栏根据左侧面板实际宽度动态定位，不再使用固定 `left: 300`；缩放控件在窄屏上移到工具栏上方，小地图同步上移；画布快捷键说明合并为顶部栏唯一入口；需验证侧栏开关、拖动调整宽度、工具栏按钮、缩放、小地图、快捷键和不同窗口宽度。
- 各用户端路由新增独立页面标题，并统一为“页面名 | 无限画布”的浏览器标题格式；需验证画布库、生图、视频、工作流、提示词、素材、素材库和登录页面标题。
- 用户端页面、登录页、顶部导航、移动端导航、配置弹窗、版本弹窗、提示词/素材弹窗及共享组件已统一改用语义颜色 token，不再使用硬编码 `stone-*` 色阶；需验证浅色/深色主题下文字对比度、边框、悬停态、错误详情和空状态。
- 工作流页面、生图页工作流抽屉和视频页 Kling 工作台改为按需加载，并显示加载占位；需验证首次打开、抽屉展开、Kling 模型切换以及加载失败后的恢复。
- 生图、视频和 Kling 工作台的标题与“侧边/底部”布局切换抽取为共享组件，三个入口的视觉和交互保持一致；需验证切换布局后偏好回填和标题显示。
- 提示词库、我的素材、素材库、素材选择器和提示词选择器统一使用共享筛选标签组件，生图、视频和 Kling 工作台统一使用共享快速参数控件；需验证分类、标签、质量和数量选择的筛选和回填结果。
- 提示词库、我的素材、素材库、画布库、图片/视频结果区、素材选择器和嵌入式工作流统一使用共享加载/空状态组件；需验证加载文案、空状态说明和按钮位置。
- Ant Design 全局字体、圆角和链接色改为与应用主题一致；素材页增加“素材库”入口，工作台和结果卡片的图标按钮补充可访问名称；需验证控件尺寸、焦点和浅深色显示。
- 画布窄屏下侧边栏和 Agent 面板改为固定覆盖层，带遮罩和关闭操作；打开一侧时自动收起另一侧，窄屏默认收起侧边栏；需验证打开/关闭、遮罩点击、面板内操作，以及桌面端双栏布局不变。

## 待重点确认

- 视频页和工作流页在浏览器观察中曾出现导航/加载超时，需要确认首屏加载是否稳定，以及是否需要进一步做客户端模块懒加载。
- 本轮未改变生成 API、任务轮询、文件存储、历史数据和画布数据结构，需对图片/视频真实任务做一次完整回归。
