## 缺陷与风险

- 【算力点】缺少 AI 代理扣点/退款的 handler 集成测试（本地代理环境会影响 upstream mock）；前端估算依赖已加载的 public 模型单价，后台改价后需刷新；用户停止任务按「不退还已开始执行任务」处理，如需退款要按未开始执行条件实现幂等退款。方案见 [ai-film-plan.md](ai-film-plan.md)。
- 【antd 弹层】Select / AutoComplete / Tooltip 与已修的 Dropdown 共用 rc-trigger 定位，在「减少动态效果」或动画被压缩的环境中可能同样停在隐藏坐标。逐页确认后，若确实失效再改成自绘，或给 ConfigProvider 注入定位兜底。
- 【影视画布】删除资产造型或场景变体时，已有镜头的 binding 边可能保留悬空 `stateId` / `variantId`；后续在删除命令层清理引用，或在删除时提示受影响的镜头。
- 【影视画布】剧本资产提取按类型精确匹配已有资产；同一资产两次提取可能被归为不同类别（如服装 ↔ 道具），会显示为新条目。后续可加跨类型同名提示或合并入口。
- 【影视画布】资产与镜头制作队列剩余项均已持久化，刷新后等待当前任务恢复再自动续跑；当前项在成功前保留，提交前刷新会重试。停止会请求云端停止并中止本地轮询；未登录或云端失败时回退为停止本地恢复，服务端任务可能继续完成。
- 【影视画布】镜头制作队列复用现有批量生成，刷新或关闭页面会中止轮询；进度不持久化，失败镜头需重新勾选；编译失败与首尾帧跳过仍只在执行清单确认中出现。
- 【影视画布】快速创建菜单仍按源节点单向展示动作，未区分从 source/target 手柄拖出；场次上的「引用角色/场景/道具」「套用风格」只创建或定位节点、不建立边，文案与实际效果有语义差，后续可改为「新建/定位」文案或加一步「选择目标镜头」；连线态「上传/从素材库选择」插入的是未连线节点。
