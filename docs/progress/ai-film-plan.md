# AI 影视板块设计

> 状态：Phase 1 已实现（项目列表、分镜表格/AI 剧本解析、分镜编辑、导演台、分镜图与视频生成）；Phase 2 已实现（项目内角色库与场景库、角色视图设定、场景四视图/全景、分镜参考图、跨项目角色与场景库）；Phase 3 第一版已实现（导演台画布视图：按场分列、拖拽平移与缩放；多选镜头批量生成分镜图与分镜视频）；分组视图按 4/9 镜一组支持整组出图出视频；Phase 4 第一版已实现剪辑预览（片段顺序、连播、总时长），导出待接合成；自定义镜头组/连线待补。目标是在现有画布与生成引擎之上，新增一条「剧本 → 角色与场景 → 导演台 → 剪辑导出」的影视生产线。

## 1. 定位

面向短剧、漫剧、宣传片等影视内容创作，与「AI 自媒体」共用同一套生成引擎，但走**项目制、分阶段**的生产流程。

- 共用：生图 / 视频生成 / 画布内核 / 素材库 / 提示词库 / 模型渠道 / Agent
- 独有：项目阶段、剧本结构、角色与场景资产、分镜与镜头管理、剪辑导出

第一版明确不做：完整 NLE（多轨转场、调色）、多人协作与权限、长片工程、专业灯光相机物理。

## 2. 设计原则

### 2.1 人性化

1. **不强制线性**：四个阶段可以自由跳转，允许「跳过剧本、直接从分镜开始」。
2. **AI 结果先建议、后应用**：剧本解析、角色提取、提示词生成都进入「待确认」列表，逐条接受/编辑/忽略，不直接覆盖用户内容。
3. **随时可回退**：解析和生成都保留版本，支持撤销；删除进回收站而不是立即消失。
4. **自动保存**：所有编辑 400ms 防抖自动保存，顶部常驻「已保存 / 保存中 / 离线」状态。
5. **断点恢复**：任务队列持久化，刷新页面后继续；失败任务可单条重试或批量重试。
6. **空状态有起点**：每个空页面给「从剧本开始 / 从模板开始 / 看示例」三个入口。
7. **成本可见**：生成前显示预计算力点，生成中显示队列，避免误操作烧点。
8. **键盘优先**：J/K 切换镜头、空格预览、⌘/Ctrl+Enter 生成、Esc 关闭浮层，和现有画布快捷键风格一致。
9. **少打断**：不使用打断式弹窗；危险操作（删除集/场、覆盖生成）才二次确认。
10. **大项目不掉帧**：列表虚拟滚动、缩略图分级加载、分镜图懒加载。

### 2.2 朋克风（延续现有视觉）

沿用现有主题令牌与组件语言，不新增第二套设计系统：

- 颜色：--acid（关键动作 / 完成）、--hot（失败 / 危险）、--hairline（结构线）、--muted（弱信息）。
- 阶段栏：mono 序号（01/02/03）+ 细横线，当前阶段用酸性短线和文字提亮，不用彩色图标块。
- 卡片：1px 描边、无阴影、hover 只提亮边框；圆角 6–12px。
- 关键 CTA（生成视频 / 导出）才用酸性实心或霓虹描边 + 轻微光晕；常规操作保持低视觉重量。
- 状态：进行中为前景色、成功为酸性、失败为洋红、未开始为弱灰。
- 禁止：大面积渐变底、彩色胶囊卡片、过多发光、超大圆角。
- 动效：150–200ms，页面切换复用 enter-up，尊重「减少动态效果」。
- 字体：标题 tracking 收紧；数字、镜号、时长用 tabular-nums 和 mono，和画布节点保持一致。

视觉细节参考现有实现：page-shell、eyebrow、neon-panel、EmptyState、FailedResultCard、canvasThemes。

## 3. 信息架构与导航

### 3.1 一级导航

~~~
我的画布
AI 自媒体 ▾   生图工作台 / 视频创作台 / 创作工作流 / 提示词库
AI 影视 ▾     我的影视项目 / 角色库 / 场景库
我的素材
~~~

- 一级「AI 影视 ▾」只放跨项目复用的入口：项目列表、角色库、场景库。
- Phase 1 先以一级直达 /film 呈现；Phase 2 加入角色库/场景库后再切换为下拉菜单。
- 分镜、预告片、剪辑都属于项目内部页面，不再占用一级/二级菜单。
- 首页创作入口宫格新增「AI 影视」卡片，与现有六种入口并列。

### 3.2 项目内阶段

~~~
剧本  →  角色与场景  →  导演台  →  剪辑导出
01       02             03         04
~~~

- 顶部固定：项目名、集数选择、阶段进度、保存状态、导出。
- 阶段可自由点击跳转；未完成的阶段显示为弱状态，不拦截进入。
- 移动端阶段栏折叠为顶部横向滚动。

### 3.3 路由

| 路由 | 页面 |
| --- | --- |
| /film | 影视项目列表 |
| /film/[id]/script | 剧本 |
| /film/[id]/cast | 角色与场景 |
| /film/[id]/storyboard | 导演台 |
| /film/[id]/edit | 剪辑导出 |
| /film/characters | 角色库（跨项目） |
| /film/scenes | 场景库（跨项目） |

## 4. 数据模型

### 4.1 前端类型（示意）

~~~ts
type FilmProject = {
    id: string;
    kind: "film";
    title: string;
    coverUrl?: string;
    visualStyle?: string;
    stage: "script" | "cast" | "storyboard" | "edit";
    canvasProjectId?: string;
    script?: FilmScript;
    characters: FilmCharacter[];
    scenes: FilmScene[];
    shots: FilmShot[];
    updatedAt: string;
};

type FilmScript = { rawText?: string; language?: string; episodes: FilmEpisode[] };

type FilmEpisode = { id: string; title: string; sceneIds: string[] };

type FilmScene = {
    id: string;
    name: string;
    location?: string;
    time?: string;
    mood?: string;
    visualStyle?: string;
    description?: string;
    visualPrompt?: string;
    referenceImageIds?: string[];
    shotIds: string[];
};

type FilmCharacter = {
    id: string;
    name: string;
    age?: string;
    gender?: string;
    traits?: string[];
    description?: string;
    visualPrompt?: string;
    referenceImageIds?: string[];
    viewAssetIds?: string[];
};

type FilmShot = {
    id: string;
    episodeId: string;
    sceneId: string;
    shotNo: string;
    shotType?: string;
    duration?: number;
    description?: string;
    dialogue?: string;
    audio?: string;
    prompt?: string;
    status: "idle" | "image_ready" | "video_ready" | "failed";
    imageNodeId?: string;
    videoTaskId?: string;
    characterIds?: string[];
};
~~~

### 4.2 存储策略

第一版**不新增影视专用后端表**：

- 影视项目 = 一个画布项目（kind 为 film），剧本/角色/场景/分镜写入项目 metadata；
- 分镜图、分镜视频仍然落到画布节点上，通过 imageNodeId / videoTaskId 关联；
- 角色与场景作为「我的素材」的扩展分类，支持跨项目复用；
- 同步、导入导出、本地优先策略与画布项目一致（未登录 localforage，登录后账号同步）。

当单项目分镜数量或协作需求超过现有 JSON 承载范围时，再拆出独立表。

## 5. 页面设计

### 5.1 项目列表 /film

~~~
┌─────────────────────────────────────────────┐
│ // FILM                                     │
│ 我的影视项目                     [+ 新建项目] │
├─────────────────────────────────────────────┤
│ [封面] 灌篮少女                进度 12/49    │
│        短剧 · 已更新 2 小时前    →           │
│ [封面] 另一个项目 ...                        │
└─────────────────────────────────────────────┘
~~~

- 新建项目提供三个入口：空白项目 / 从剧本开始 / 从模板开始。
- 卡片显示封面、标题、阶段进度、更新时间；hover 只提亮边框。
- 空状态：说明三步流程 + 「先用示例剧本试试」。

### 5.2 剧本 /film/[id]/script

三栏布局：

- 左：剧本导入（粘贴完整剧本 / 上传文件）、剧本语言、场景/分镜数量、视觉风格、AI 解析入口。
- 中：剧集结构树（集 → 场 → 分镜），支持未完成/已完成筛选，显示完成度。
- 右：当前分镜详情（画面描述、动作描述、音频、出场角色、情绪、图片/视频状态、生成入口）。

关键交互：

- 「AI 解析剧本」结果进入**待确认**状态，可逐条接受、编辑、忽略，也可以整段替换；
- 解析进度可见，可中断、可继续；
- 每场可标记完成，右侧展示「前往导演台」的下一步引导；
- 不强制先导入剧本：可以直接新建分镜，后续再补剧本。

### 5.3 角色与场景 /film/[id]/cast

- 左：生成控制台（角色/场景名称、描述、性别年龄、性格、视觉风格、参考图、生成内容：三视图 / 表情设定 / 比例设定 / 动作设定）。
- 中：角色库、场景库网格，每个资产显示预览、视图数量、名称。
- 右：选中资产的详情（多视图大图、角色信息、视觉特征、编辑）。

关键交互：

- 角色/场景生成结果自动入库，可**跨项目复用**；
- 生成分镜时可以直接引用角色卡与场景卡，保证一致性；
- 资产删除进回收站；引用关系在删除前提示。

### 5.4 导演台 /film/[id]/storyboard

两种模式并存，顶部切换：

1. **分镜列表模式**：按集/场分组，镜头卡显示镜号、景别、时长、参考图、生成状态；支持分组批量生成 3/15 秒视频。
2. **无限画布模式**：直接复用现有画布内核，镜头以「镜头组」节点呈现，支持九宫格分组、连线、拖拽。

~~~
┌───────────────────────────────────────────┐
│ // STORYBOARD      分镜列表 │ 无限画布  已保存 │
├───────────────────────────────────────────┤
│ 1-1 乡村公路/大巴车                      0/5 │
│ [镜头卡] [镜头卡] [镜头卡]  [+ 添加镜头]     │
│ 1-2 中学操场                             0/6 │
└───────────────────────────────────────────┘
~~~

关键交互：

- 镜头拖拽排序，批量选中后统一生成；
- 生成前显示预计算力点，生成中显示任务队列；
- 失败镜头标红，可单条重试，也可批量重试；
- 镜头卡 hover 出现「重新生成 / 查看详情 / 引用」；
- 「发送到剪辑」按分组输出片段，保留镜头顺序。

### 5.5 剪辑导出 /film/[id]/edit

轻量时间轴，不做完整 NLE：

- 片段拖拽排序、时长裁剪、首尾帧预览；
- 字幕/配音作为轨道占位，第一版仅支持导入或简单生成；
- 导出选项：分辨率、码率、是否烧录字幕；
- 预告片：按选中的镜头序列快速拼一条预览。

## 6. 与现有能力的复用矩阵

| 影视能力 | 现有模块 | 复用方式 | 需新增 |
| --- | --- | --- | --- |
| 剧本解析 | Agent / 文本模型 | 复用 | 剧本结构 schema 与待确认列表 |
| 角色三视图、表情 | 生图工作台 | 复用生成与参考图 | 角色资产类型 |
| 场景概念图、四视图 | 生图 / 全景 | 复用 | 场景资产类型 |
| 分镜图 | 画布节点 + 批量生成 | 复用 | 镜头卡 / 镜头组节点 |
| 分镜视频 | 视频创作台 | 复用任务接口 | 镜头与任务映射 |
| 无限画布 | 画布 | 复用画布内核 | 镜头组节点、九宫格分组 |
| 素材 | 我的素材 | 复用 | 角色 / 场景分类 |
| 剪辑 | 无 | 新增 | 时间轴组件 |

## 7. 生成与任务

- 所有生成统一走现有画布任务接口，影视只做编排，不复制生成逻辑；
- 任务队列在前端持久化，刷新后恢复轮询；
- 失败提示复用现有「失败卡 + 详情 + 重试」，并接入 AI 日志的失败原因；
- 生成前统一显示预计算力点；
- 同一镜头重复生成保留历史版本，不覆盖上一次结果。

## 8. 组件清单

- FilmStageRail：阶段进度与跳转
- FilmProjectCard：项目卡
- EpisodeTree：集/场/分镜树
- ShotCard / ShotGroup：镜头卡与分组
- CharacterCard / SceneCard：角色、场景资产卡
- StageProgress：阶段完成度
- CostBadge：预计算力点
- TaskQueuePopover：生成队列
- AutoSaveIndicator：保存状态
- ConfirmDanger：危险操作确认

## 9. 分期计划

### Phase 1：项目骨架 + 剧本 + 分镜（MVP）

- AI 影视一级入口、项目列表、项目内阶段导航；
- 剧本导入、AI 解析（待确认）、剧集结构树；
- 分镜列表与批量生成分镜图；
- 自动保存与任务队列。

验收：从剧本到一批分镜图可以在一个项目内完成，刷新不丢数据。

### Phase 2：角色库与场景库

- 角色三视图/表情生成与入库；
- 场景概念图/四视图/全景；
- 分镜引用角色与场景，保证一致性。

验收：同一角色在多个分镜中的外观可复用，不重复描述。

### Phase 3：导演台（无限画布模式）

- 分镜列表 ↔ 无限画布双模式；
- 镜头组、九宫格分组、分组生成视频；
- 任务队列与失败重试完善。

验收：一集分镜可以在画布内完成编排并批量生成视频片段。

### Phase 4：剪辑导出

- 轻量时间轴、片段排序与裁剪；
- 字幕/配音占位、预告片；
- 导出配置。

验收：能把生成的片段拼成一条可导出的短片。

## 10. 风险与取舍

- **角色一致性**是核心难点：第一版用参考图 + 固定 seed + 角色卡复用，不承诺完全一致；
- **视频生成成本与时长**：用分组生成与队列控制，避免一次提交整集；
- **数据模型**：先复用画布项目 JSON，超过承载后拆表；
- **边界**：影视与自媒体共用引擎，不共用页面与导航；
- **第一版不做完整剪辑**，避免拖慢主链路。
